## Как устроен разбор

В решениях сохранены промежуточные преобразования. Итоговые ответы выделены рамкой, а рядом оставлены пояснения к основным переходам

Для математических выражений используется LaTeX: формулы внутри текста записаны через `$...$`, отдельные формулы - через `$$...$$`

## Построение графиков

Исследование функции, таблицы знаков и вычисления удобно хранить в Obsidian. Для построения графика можно использовать [Desmos](https://www.desmos.com/calculator), а затем добавить в заметку ссылку или изображение

Для функций из примеров можно ввести:

```text
y = x^3/(3-x)^3
y = x^4/(1+x)^3
y = C*(x^3+9*x)/(x^2-4)
```

В последней функции $C$ используется вместо неразборчивого коэффициента из условия второго варианта

> <span style="background-color: rgba(224, 108, 117, 0.28);">Важно!</span>
> В записи варианта 2 перед дробью сохранилось `1/?`. Точное значение коэффициента неизвестно, поэтому в разборе принято $C\ne0$. При $C>0$ знаки функции и её производных сохраняются, а при $C<0$ меняются на противоположные

## Обозначения

| Обозначение | Значение |
|---|---|
| $D(f)$ | Область определения функции |
| $E(f)$ | Область значений функции |
| $y'$ или $f'(x)$ | Первая производная |
| $y''$ или $f''(x)$ | Вторая производная |
| $y^{(n)}$ | Производная порядка $n$ |
| $u_x$ | Частная производная функции $u$ по $x$ |
| $du$ | Полный дифференциал первого порядка |
| $d^2u$ | Полный дифференциал второго порядка |
| $\lim_{x\to a-0}$ | Односторонний предел при приближении к $a$ слева |
| $\lim_{x\to a+0}$ | Односторонний предел при приближении к $a$ справа |
