## <span style="color: #D58EAD;">1. Сохранение неравенства</span>

> Если $f(x) \le g(x)$ в некоторой проколотой окрестности точки $x_0$, то $a \le b$

**Доказательство**

Пусть $\lim\limits_{n \to \infty} x_n = x_0$, тогда по определению предела по Гейне:

$$f(x_n) \to a \quad \text{и} \quad g(x_n) \to b \qquad (n \to \infty)$$

По условию $f(x) \le g(x)$. При <span style="color: #AE91CE;">достаточно больших</span> $n$ точки $x_n$ попадают в окрестность точки $x_0$, где $f(x_n) \le g(x_n)$

Переходя к пределу при $n \to \infty$, получаем:

$$a \le b$$

## <span style="color: #D58EAD;">2. Теорема о двух милиционерах</span>

> Если $f(x) \le h(x) \le g(x)$ и $a = b$ в некоторой проколотой окрестности точки $x_0$, то
>
> $$\lim_{x \to x_0} h(x) = a = b$$

**Доказательство**

Фиксируем $\varepsilon > 0$:

$$\exists \delta_1:\ |x - x_0| < \delta_1 \implies |f(x) - a| < \varepsilon$$

$$\exists \delta_2:\ |x - x_0| < \delta_2 \implies |g(x) - b| < \varepsilon$$

Тогда:

$$a - \varepsilon < f(x) \le h(x) \le g(x) < \varepsilon + b = a$$

$$a - \varepsilon \le h(x) \le \varepsilon + b = a$$

$$\implies \lim_{x \to x_0} h(x) = a = b$$
