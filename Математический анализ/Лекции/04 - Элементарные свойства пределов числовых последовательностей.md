## <span style="color: #D58EAD;">1. Предел единственен</span>

Пусть $\exists \lim\limits_{n \to \infty} x_n = a$ и $\exists \lim\limits_{n \to \infty} x_n = b$

**Доказательство**

$$\forall \varepsilon > 0\ \exists N_1 = N_1(\varepsilon) \in \mathbb{N}:\ \forall n > N_1 \quad |x_n - a| < \frac{\varepsilon}{2}$$

$$\forall \varepsilon > 0\ \exists N_2 = N_2(\varepsilon) \in \mathbb{N}:\ \forall n > N_2 \quad |x_n - b| < \frac{\varepsilon}{2}$$

Пусть $N = \max\{N_1, N_2\}$, тогда $\forall n > N$:

$$|b - a| = |b - x_n + x_n - a| \le |b - x_n| + |x_n - a| = |x_n - b| + |x_n - a| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$

Получаем $|b - a| < \varepsilon$

Значит, расстояние между $b$ и $a$ может быть сколь угодно малым (произвольность $\varepsilon$)

Это означает, что $a = b$

## <span style="color: #D58EAD;">2. Теорема о двух милиционерах</span>

Пусть $x_n \le y_n \le z_n$, $\forall n \in \mathbb{N}$

Если $\lim\limits_{n \to \infty} x_n = \lim\limits_{n \to \infty} z_n = a$, то

$$\lim_{n \to \infty} y_n = a$$

**Доказательство**

$$\forall \varepsilon > 0\ \exists N_1 = N_1(\varepsilon) \in \mathbb{N}:\ \forall n > N_1 \quad |x_n - a| < \varepsilon$$

$$\forall \varepsilon > 0\ \exists N_2 = N_2(\varepsilon) \in \mathbb{N}:\ \forall n > N_2 \quad |z_n - a| < \varepsilon$$

Раскрываем модули:

$$-\varepsilon < x_n - a < \varepsilon \qquad -\varepsilon < z_n - a < \varepsilon$$

$$a - \varepsilon < x_n < \varepsilon + a \qquad a - \varepsilon < z_n < \varepsilon + a$$

Пусть $N = \max\{N_1, N_2\}$, тогда $\forall n > N$:

$$a - \varepsilon < x_n \le y_n \le z_n < \varepsilon + a$$

$$a - \varepsilon < y_n < \varepsilon + a \text{, т.е.}$$

$$\exists \lim_{n \to \infty} y_n = a$$

## <span style="color: #D58EAD;">3. Ограниченность</span>

Если последовательность $x_n$, $n \in \mathbb{N}$, сходится, т.е. $\exists \lim\limits_{n \to \infty} x_n = a$, то $x_n$ - ограниченная величина

> <span style="color: #D58EAD;">Определение ограниченной последовательности</span>:
>
> $$\exists M > 0:\ \forall n \in \mathbb{N} \quad |x_n| \le M$$

**Доказательство**

Возьмем $\varepsilon = 1$:

$$\exists N_1 = N_1(1) \in \mathbb{N}:\ \forall n > N_1 \quad |x_n - a| < 1$$

$$||x_n| - |a|| \le |x_n - a| < 1$$

$$|x_n| - |a| < 1$$

$$|x_n| < 1 + |a|$$

Пусть $M = \max\{|x_1|, |x_2|, \dots, |x_{N_1}|, |a| + 1\}$

Очевидно, $|x_n| < M$, $\forall n \in \mathbb{N} \implies x_n$ - ограниченная
