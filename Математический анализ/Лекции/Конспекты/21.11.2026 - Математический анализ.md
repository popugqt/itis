## <span style="color: #D58EAD;">1. Теорема Ферма (необходимое условие экстремума)</span>

> <span style="color: #D58EAD;">Теорема Ферма</span> (необходимое условие экстремума). Пусть функция $f(x)$ определена в некотором промежутке $X$ и во внутренней точке $c$ этого промежутка принимает наибольшее (наименьшее) значение. Если существует конечная двусторонняя производная $f'(c)$, то $f'(c) = 0$

**Доказательство** (от противного)

Пусть $f(c)$ - наибольшее значение функции $f(x)$ на $X$. Предположим, что $f'(c) \neq 0$. Тогда возможны <span style="color: #AE91CE;">два случая</span>:

1. $f'(c) > 0$ $\Rightarrow$ $f$ возрастает на $X$ $\Rightarrow$ при $x > c$ имеем $f(x) > f(c)$ - <span style="color: #e0313a;">противоречие</span>
2. $f'(c) < 0$ $\Rightarrow$ $f$ убывает на $X$ $\Rightarrow$ при $x < c$ имеем $f(x) > f(c)$ - <span style="color: #e0313a;">противоречие</span>

Следовательно, $\boxed{f'(c) = 0}$ ∎

## <span style="color: #D58EAD;">2. Случай отсутствия экстремума</span>

> Если $f'(x) > 0$ при $x < x_0$ и при $x > x_0$ (или $f'(x) < 0$ при $x < x_0$ и при $x > x_0$), то есть при переходе через точку $x_0$ производная <span style="color: #D58EAD;">не меняет знака</span>, то $f(x)$ всегда возрастает (убывает) $\Rightarrow$ в точке $x_0$ экстремума <span style="color: #e0313a;">нет</span>

## <span style="color: #D58EAD;">3. Пример: полное исследование функции</span>

**Задача.** Построить график функции с полным исследованием

**Дано**

$$y = x^2 + \frac{1}{x}$$

### <span style="color: #D58EAD;">Шаг 1. Область определения</span>

$$x \in \mathbb{R} \setminus \{0\}$$

### <span style="color: #D58EAD;">Шаг 2. Чётность и нечётность</span>

Функция <span style="color: #e0313a;">общего вида</span> (ни чётная, ни нечётная)

> Если бы $f(-x) = -f(x)$, функция была бы нечётной, её график симметричен относительно точки $(0; 0)$, и достаточно исследовать её при $x \in [0; +\infty)$

### <span style="color: #D58EAD;">Шаг 3. Симметрия</span>

Симметрии <span style="color: #e0313a;">нет</span>

### <span style="color: #D58EAD;">Шаг 4. Периодичность</span>

Проверяем условие периодичности:

$$(x + T)^2 + \frac{1}{x + T} = x^2 + \frac{1}{x}$$

Равенство верно только при $T = 0$ $\Rightarrow$ функция <span style="color: #e0313a;">не периодична</span>

### <span style="color: #D58EAD;">Шаг 5. Нули функции и промежутки знакопостоянства</span>

<span style="color: #AE91CE;">Нули</span> - корни уравнения $f(x) = 0$:

$$x^2 + \frac{1}{x} = 0 \;\Rightarrow\; x^3 + 1 = 0,\ x \neq 0 \;\Rightarrow\; \boxed{x = -1}$$

Знаки $f(x)$:

| Промежуток | $(-\infty; -1)$ | $(-1; 0)$ | $(0; +\infty)$ |
|---|---|---|---|
| $f(x)$ | $+$ | $-$ | $+$ |

### <span style="color: #D58EAD;">Шаг 6. Экстремумы и промежутки монотонности</span>

$$f'(x) = 2x - \frac{1}{x^2}$$

<span style="color: #AE91CE;">Критические точки:</span> $2x^3 - 1 = 0$, $x \neq 0$ $\Rightarrow$ $\boxed{x_0 = \frac{1}{\sqrt[3]{2}}}$

| Промежуток | $(-\infty; 0)$ | $\left(0; \frac{1}{\sqrt[3]{2}}\right)$ | $\left(\frac{1}{\sqrt[3]{2}}; +\infty\right)$ |
|---|---|---|---|
| $f'(x)$ | $-$ | $-$ | $+$ |
| $f(x)$ | убывает | убывает | возрастает |

<span style="color: #8FBF8F;">$x = \frac{1}{\sqrt[3]{2}}$ - точка минимума</span>

Проверка по второй производной:

$$f''{\left(\frac{1}{\sqrt[3]{2}}\right)} = 2 + 2 \cdot \left(\sqrt[3]{2}\right)^3 = 6 > 0$$

### <span style="color: #D58EAD;">Шаг 7. Точки перегиба, выпуклость и вогнутость</span>

$$f''(x) = 2 + \frac{2}{x^3}$$

$$f''(x) = 0 \;\Rightarrow\; 2x^3 + 2 = 0,\ x \neq 0 \;\Rightarrow\; x^3 = -1 \;\Rightarrow\; \boxed{x = -1}$$

<span style="color: #8FBF8F;">$x = -1$ - точка перегиба</span>

### <span style="color: #D58EAD;">Шаг 8. Асимптоты</span>

<span style="color: #D58EAD;">Наклонная асимптота</span> $y = kx + b$ (при $x \to +\infty$ и $x \to -\infty$):

$$k = \lim_{x \to \pm\infty} \frac{f(x)}{x}, \qquad b = \lim_{x \to \pm\infty} \left( f(x) - kx \right)$$

> <span style="color: #e0313a;">Важно!</span>
> Если $k$ и/или $b = \pm\infty$, то асимптоты <span style="color: #e0313a;">нет</span>

Для нашей функции:

$$k = \lim_{x \to \pm\infty} \left( x + \frac{1}{x^2} \right) = \pm\infty + 0 = \pm\infty$$

<span style="color: #e0313a;">Наклонных асимптот нет</span>. Вертикальная асимптота - $x = 0$

### <span style="color: #D58EAD;">Шаг 9. Поведение функции на границах области определения</span>

$$\lim_{x \to -0} \left( x^2 + \frac{1}{x} \right) = 0 - \infty = -\infty$$

$$\lim_{x \to +0} \left( x^2 + \frac{1}{x} \right) = 0 + \infty = +\infty$$

$$\lim_{x \to +\infty} \left( x^2 + \frac{1}{x} \right) = +\infty + 0 = +\infty$$

$$x \to -\infty \;\Rightarrow\; y \to -\infty$$

### <span style="color: #D58EAD;">Шаг 10. Значения функции в характерных точках</span>

$$y(-1) = 0$$

$$y_0 = y{\left( \frac{1}{\sqrt[3]{2}} \right)} \text{ - значение в точке минимума}$$

**Вывод (график).** График проходит через точку $(-1; 0)$, имеет точку перегиба при $x = -1$, точку минимума при $x = \frac{1}{\sqrt[3]{2}}$, вертикальную асимптоту $x = 0$ (слева уходит в $-\infty$, справа приходит из $+\infty$), ветви уходят в $\pm\infty$

## <span style="color: #D58EAD;">4. Первообразная и неопределённый интеграл</span>

> <span style="color: #D58EAD;">Первообразная</span> функции $f(x)$ - это функция $F(x)$, производная которой равна $f(x)$, то есть $F'(x) = f(x)$

Так как $C' = 0$, то $(F(x) + C)' = F'(x) = f(x)$ $\Rightarrow$ $F(x) + C$ - <span style="color: #8FBF8F;">тоже первообразная</span>

> <span style="color: #D58EAD;">Теорема</span>. Две первообразные функции $f(x)$ могут отличаться только на константу: если $F'(x) = f(x)$ и $\Psi'(x) = f(x)$, то $F(x) - \Psi(x) = C \in \mathbb{R}$

**Доказательство**

Обозначим $\varphi(x) = F(x) - \Psi(x)$. Тогда:

$$\varphi'(x) = F'(x) - \Psi'(x) = f(x) - f(x) = 0$$

По <span style="color: #D58EAD;">теореме конечного приращения</span> (Лагранжа) для любых $a$, $b$ ($a < c < b$):

$$\varphi(b) - \varphi(a) = \varphi'(c) \cdot (b - a) = 0 \;\Rightarrow\; \varphi(b) = \varphi(a) = \text{const}$$

То есть $F(x) - \Psi(x) = C$ ∎

> <span style="color: #D58EAD;">Неопределённый интеграл</span> - множество всех первообразных функции $f(x)$:
> $$\int f(x)\,dx := F(x) + C$$

Таблица значений неопределённых интегралов основных элементарных функций - см. учебник

**Пример**

$$\int \sin{x}\,dx = -\cos{x} + C$$

Проверка дифференцированием:

$$\left( -\cos{x} + C \right)' = -1 \cdot \left( -\sin{x} \right) + 0 = \sin{x} \;\checkmark$$

## <span style="color: #D58EAD;">5. Интегрирование по частям</span>

> Пусть $u = u(x)$, $v = v(x)$, существуют непрерывные $u'(x)$, $v'(x)$. Тогда:
> $$\int u(x) \cdot v'(x)\,dx = u(x) \cdot v(x) - \int u'(x) \cdot v(x)\,dx \;(+ C)$$

**Доказательство**

По правилу дифференцирования произведения:

$$(uv)' = u'v + v'u$$

Тогда:

$$uv = \int (uv)'\,dx + C = \int \left( u'v + v'u \right) dx + C = \int u'v\,dx + \int v'u\,dx + C$$

Отсюда:

$$\int u \cdot v'\,dx = uv - \int u' \cdot v\,dx + C \;\blacksquare$$
