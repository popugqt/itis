## <span style="color: #D58EAD;">1. Полные классы</span>

> Класс функций называется <span style="color: #D58EAD;">полным</span>, если $[C] = F$

Примеры:

| Полные классы | Неполные классы |
|---|---|
| $\{\land, \lor, \neg\}$ | $\{\land, \lor\}$ |
| $\{1, \land, +\}$ | $\{0, 1\}$ |
| $\{\mid\}$ | $\{\neg\}$ |
| $\{\downarrow\}$ | $T_0, T_1, S, L, M$ |
| $F$ | |

---

## <span style="color: #D58EAD;">2. Теорема Поста о полноте</span>

> **Теорема Поста.** $[C] = F$ (то есть $C$ - полный класс) $\Leftrightarrow$
> $$C \not\subseteq T_0,\quad C \not\subseteq T_1,\quad C \not\subseteq L,\quad C \not\subseteq S,\quad C \not\subseteq M$$

Примеры применения:

- $\{\neg, \land, \lor\}$: $\neg \notin T_0, T_1, M$; $\lor, \land \notin S, L$
- $\{\neg, \land\}$, $\{\neg, \lor\}$ - аналогично
- $\{1, +, \land\}$: $1 \notin T_0, S$; $+ \notin T_1, M$; $\land \notin L, S$

**Доказательство**

$(\Rightarrow)$ Классы $T_0, T_1, S, L, M$ <span style="color: #e0313a;">не содержатся</span> друг в друге. Если $C \subseteq D$, то $[C] \subseteq [D] \ne F$ - противоречие с полнотой

Контрпримеры для каждой пары классов:

| Класс | Функция | Принадлежность |
|---|---|---|
| $T_0$ | $0$ | $0 \in T_0$, $\notin T_1, S$ |
| $T_0$ | $\land$ | $\land \in T_0$, $\notin L$ |
| $T_0$ | $+$ | $+ \in T_0$, $\notin M$ |
| $T_1$ | $1$ | $1 \in T_1$, $\notin T_0, S$ |
| $T_1$ | $\land$ | $\land \in T_1$, $\notin L$ |
| $T_1$ | $\leftrightarrow$ | $\leftrightarrow \in T_1$, $\notin M$ |
| $M$ | $1$ | $1 \in M$, $\notin T_0$ |
| $M$ | $0$ | $0 \in M$, $\notin T_1$ |
| $M$ | $\land$ | $\land \in M$, $\notin L, S$ |
| $S$ | $\bar x$ | $\bar x \in S$, $\notin T_0, T_1, M$ |
| $S$ | $xy \lor xz \lor yz$ | $\in S$, $\notin L$ |
| $L$ | $\bar x$ | $\bar x \in L$, $\notin T_0, T_1$ |
| $L$ | $x + y$ | $x + y \in L$, $\notin S, M$ |

$(\Leftarrow)$ Надо доказать, что класс полный, то есть $\&, \neg, 0, 1 \in [C]$. Схема доказательства:

![[коллоквиум_пост_схема.png]]

Обозначения:

| Функция | Принадлежность | Что даёт |
|---|---|---|
| $f_0 \in C \setminus T_0$ | $\neg$ или $0, 1$ | шаг 1 |
| $f_1 \in C \setminus T_1$ | $\neg$ или $0, 1$ | шаг 1 |
| $f_L \in C \setminus L$ | $0, 1, \neg, \&$ | шаг 4 |
| $f_M \in C \setminus M$ | $\neg$ | шаг 2 |
| $f_S \in C \setminus S$ | $0, 1$ | шаг 3 |

Переходы на схеме:

1. По лемме для $T_0$, $T_1$
2. По лемме о немонотонной функции
3. По лемме о несамодвойственной функции
4. По лемме о нелинейной функции

## <span style="color: #D58EAD;">3. Лемма для</span> $T_0$ и $T_1$

> **Лемма.** Если $f_0 \notin T_0$, $f_1 \notin T_1$, то <span style="color: #AE91CE;">либо</span> $\neg \in [f_0, f_1]$, <span style="color: #AE91CE;">либо</span> $0, 1 \in [f_0, f_1]$

**Доказательство**

$f_0(0 \ldots 0) = 1$

**Случай 1.** $f_0(1 \ldots 1) = 0$ $\Rightarrow$

$$\bar x = f_0(x \ldots x) \in [f_0] \subseteq [f_0, f_1]$$

**Случай 2.** $f_0(1 \ldots 1) = 1$ $\Rightarrow$

$$1 = f_0(x \ldots x) \in [f_0] \subseteq [f_0, f_1]$$
$$0 = f_1(1 \ldots 1) = f_1(f_0(x_1 \ldots x_n) \ldots f_0(x_1 \ldots x_n))$$

- получены <span style="color: #8FBF8F;">обе константы</span> $\blacksquare$

## <span style="color: #D58EAD;">4. Базисы полных классов</span>

> <span style="color: #D58EAD;">Базис полного класса</span> - это подмножество $B \subseteq C$, где $C$ - полный класс, если $B$ - полный и <span style="color: #e0313a;">не существует</span> такого $B' \subseteq B$, $B' \ne B$, что $B'$ - полный

---

## <span style="color: #D58EAD;">5. Максимальное количество элементов базисов и примеры</span>

> Любой базис полного класса состоит из <span style="color: #AE91CE;">не более чем четырёх</span> функций (следствие теоремы Поста)

Примеры:

| Число функций | Базисы | Проверка минимальности |
|---|---|---|
| из 1 функции | $\{\mid\}$, $\{\downarrow\}$ | - |
| из 2 функций | $\{\&, \neg\}$, $\{\lor, \neg\}$, $\{\to, 0\}$ | - |
| из 3 функций | $\{+, 1, \&\}$ | $\{1, +\} \subseteq L$; $\{1, \&\} \subseteq T_1 \cap M$; $\{+, \&\} \subseteq T_0$ |
| из 4 функций | $\{0, 1, \&, x + y + z\}$ | $0 \notin T_1, S$; $1 \notin T_0, S$; $\& \notin L, S$; $x + y + z \notin M$ |

Для базиса из 4 функций <span style="color: #AE91CE;">каждая</span> тройка неполна:

- $\{0, 1, \&\} \subseteq M$
- $\{0, 1, x + y + z\} \subseteq L$
- $\{0, \&, x + y + z\} \subseteq T_0$
- $\{1, \&, x + y + z\} \subseteq T_1$

## <span style="color: #D58EAD;">6. Предполные классы и их полное описание</span>

> <span style="color: #D58EAD;">Предполный класс</span> - <span style="color: #D58EAD;">максимальный</span> неполный замкнутый класс, то есть:
> 1. $[C] \ne F$
> 2. $C = [C]$
> 3. Если $C \subseteq D$, $[D] \ne F$, $[D] = D$, то $C = D$

> **Предложение.** $C$ - предполный $\Leftrightarrow$
> 1. $[C] \ne F$
> 2. $C = [C]$
> 3. $\forall f \notin C \quad [C \cup \{f\}] = F$

**Доказательство**

$(\Rightarrow)$ $f \notin C$, $D = [C \cup \{f\}]$, тогда $C \subseteq D = [D]$, но $C \ne D$ (так как $C \not\ni f$, а $D \ni f$) $\Rightarrow$ $D = F$

$(\Leftarrow)$ Предположим, что $C \subseteq D$, $D \ne C$, но $D = [D] \ne F$. Существует $f \in D \setminus C$, тогда

$$[C \cup \{f\}] = F$$
$$[C \cup \{f\}] \subseteq [D] = D \ \Rightarrow\ D = F$$

- <span style="color: #e0313a;">противоречие</span> $\blacksquare$

> **Предложение.** $C$ - предполный $\Leftrightarrow$ $C = T_0$ или $T_1$, или $L$, или $M$, или $S$

**Доказательство**

$(\Rightarrow)$ $C$ предполный $\Rightarrow$ $[C] \ne F$ $\Rightarrow$ по теореме Поста $C \subseteq T_0$ или $T_1$, или $L$, или $M$, или $S$. Для $D = T_0, T_1, M, S, L$: $D = [D] \ne F$. Тогда $C = D$

$(\Leftarrow)$ Проверяем <span style="color: #AE91CE;">каждый</span> из пяти классов по критерию выше: любая добавленная функция $f \notin C$ выводит систему за пределы соответствующего класса, и по теореме Поста $[C \cup \{f\}] = F$

- $C = T_0$: $f \notin T_0$. По теореме Поста $T_0 \not\subseteq T_1, S, L, M$ $\Rightarrow$ $f \notin T_0 \not\subseteq T_1, S, L, M$: $0 \in T_0 \not\subseteq T_1, S$; $\land \in T_0 \not\subseteq L$; $\oplus \in T_0 \not\subseteq M$ $\Rightarrow$ $[T_0 \cup \{f\}] = F$
- $C = T_1$: $f \notin T_1 \not\subseteq T_0, S, L, M$: $1 \in T_1 \not\subseteq T_0, S$; $\land \in T_1 \not\subseteq L$; $\leftrightarrow \in T_1 \not\subseteq M$ $\Rightarrow$ $[T_1 \cup \{f\}] = F$
- $C = L$: $f \notin L \not\subseteq T_0, T_1, M, S$: $\neg \in L \not\subseteq T_0, T_1$; $x + y \in L \not\subseteq M, S$ $\Rightarrow$ $[L \cup \{f\}] = F$
- $C = M$: $f \notin M \not\subseteq T_0, T_1, L, S$: $1 \in M \not\subseteq T_0$; $0 \in M \not\subseteq T_1$; $\land \in M \not\subseteq L, S$ $\Rightarrow$ $[M \cup \{f\}] = F$
- $C = S$: $f \notin S \not\subseteq T_0, T_1, L, M$: $\neg \in S \not\subseteq T_0, T_1, M$; $xy \lor xz \lor yz \notin L$ $\Rightarrow$ $[S \cup \{f\}] = F$ $\blacksquare$

> **Вывод.** Полное описание предполных классов - это в точности пять классов Поста: $T_0$, $T_1$, $L$, $M$, $S$
