## <span style="color: #D58EAD;">1. Определение многочлена Жегалкина</span>

> <span style="color: #D58EAD;">Многочлен Жегалкина</span> - сумма (по модулю 2) нескольких элементарных конъюнктов <span style="color: #e0313a;">без отрицаний</span>

Вывод из СДНФ:

$$f(x_1, x_2, \ldots, x_n) = \bigvee_{(\sigma_1, \ldots, \sigma_n) \in I} x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n} = \bigoplus_{(\sigma_1, \ldots, \sigma_n) \in I} x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n}$$

где $I = \{\,(\sigma_1, \ldots, \sigma_n) \mid f(\sigma_1, \ldots, \sigma_n) = 1\,\}$

Заметим, что если $(\sigma_1 \ldots \sigma_n) \ne (\tau_1 \ldots \tau_n)$, то

$$(x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n}) \cdot (x_1^{\tau_1} \cdot x_2^{\tau_2} \ldots x_n^{\tau_n}) = 0$$

поэтому дизъюнкцию <span style="color: #AE91CE;">можно заменить</span> суммой по модулю 2. Далее подставляем $x_i^{\sigma_i} = x_i + \bar\sigma_i$:

$$\bigoplus_{(\sigma_1 \ldots \sigma_n) \in I} x_1^{\sigma_1} \ldots x_n^{\sigma_n} = \bigoplus_{(\sigma_1 \ldots \sigma_n) \in I} (x_1 + \bar\sigma_1) \ldots (x_n + \bar\sigma_n) = \bigoplus_{(\sigma_1 \ldots \sigma_n) \le (\tau_1 \ldots \tau_n)} x_1^{\tau_1} \ldots x_n^{\tau_n}$$

$$= \bigoplus_{(\sigma_1 \ldots \sigma_n) \in B^n} \ \bigoplus_{(\tau_1 \ldots \tau_n) \ge (\sigma_1 \ldots \sigma_n)} f(\sigma_1 \ldots \sigma_n)\, x_1^{\tau_1} \cdot x_2^{\tau_2} \ldots x_n^{\tau_n} = \bigoplus_{(\tau_1 \ldots \tau_n) \in B^n} \left( \bigoplus_{(\sigma_1 \ldots \sigma_n) \le (\tau_1 \ldots \tau_n)} f(\sigma_1 \ldots \sigma_n) \right) x_1^{\tau_1} \ldots x_n^{\tau_n}$$

- <span style="color: #D58EAD;">многочлен Жегалкина</span>

## <span style="color: #D58EAD;">3. Теорема о существовании и единственности многочлена Жегалкина</span>

> **Теорема.** Любая булева функция $f: B^n \to B$ представляется в виде многочлена Жегалкина, причём <span style="color: #8FBF8F;">единственным образом</span>

### <span style="color: #D58EAD;">Доказательство существования</span>

$$f(x_1 \ldots x_n) = \bigvee_{(\sigma_1 \ldots \sigma_n) \in I} x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n} = \bigoplus_{(\sigma_1 \ldots \sigma_n) \in I} x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n}$$

где $I = \{\,(\sigma_1 \ldots \sigma_n) \mid f(\sigma_1 \ldots \sigma_n) = 1\,\}$. Заметим, что если $(\sigma_1 \ldots \sigma_n) \ne (\tau_1 \ldots \tau_n)$, то

$$(x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n}) \cdot (x_1^{\tau_1} \cdot x_2^{\tau_2} \ldots x_n^{\tau_n}) = 0$$

Докажем, что $x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n}$ представим в виде многочлена Жегалкина. Если $\sigma_1 = 0$, $\sigma_2 = 0$, $\ldots$, $\sigma_k = 0$, $\sigma_{k+1} = 1$, $\sigma_{k+2} = 1$, $\ldots$, $\sigma_n = 1$, то

$$x_1^{\sigma_1} \cdot x_2^{\sigma_2} \ldots x_n^{\sigma_n} = \bar x_1 \bar x_2 \ldots \bar x_k \cdot x_{k+1} x_{k+2} \ldots x_n = (1 + x_1)(1 + x_2) \ldots (1 + x_k) \cdot x_{k+1} x_{k+2} \ldots x_n = \sum_{K} K \cdot x_{k+1} \cdot x_{k+2} \ldots x_n,$$

где суммирование проводится по <span style="color: #AE91CE;">всем конъюнктам</span> $K$ без отрицания от переменных $x_1, \ldots, x_k$. Сумма таких многочленов - снова многочлен Жегалкина $\blacksquare$

### <span style="color: #D58EAD;">Доказательство единственности</span>

Пусть $N = 2^{2^n}$ и $f_1, f_2 \ldots f_N$ - все булевы функции от $n$ аргументов. Пусть $G_i$ - количество различных многочленов Жегалкина функции $f_i$, $i = \overline{1, N}$. В силу доказанного $G_i \ge 1$, $i = \overline{1, N}$. Тогда для количества $G$ всех многочленов Жегалкина от $n$ аргументов имеем

$$G = \sum_{i=1}^{N} G_i \ge \sum_{i=1}^{N} 1 = N = 2^{2^n}$$

Так как существует только $2^n$ конъюнктов без отрицаний, всего многочленов Жегалкина от $n$ переменных ровно $2^{2^n}$, то $G_i = 1$ для каждого $i = \overline{1, N}$, то есть <span style="color: #AE91CE;">каждая</span> $f_i$ имеет <span style="color: #8FBF8F;">только один</span> многочлен Жегалкина $\blacksquare$

## <span style="color: #D58EAD;">4. Методы построения многочлена Жегалкина</span>

Формулы над $\{\&, +, 1\}$:

$$\bar x = x + 1$$
$$x \lor y = \overline{\bar x \cdot \bar y} = \bar x \bar y + 1 = (x + 1)(y + 1) + 1 = xy + x + y$$
$$xy = xy$$
$$x \to y = \overline{x \bar y} = x\bar y + 1 = x(y + 1) + 1 = xy + x + 1$$
$$x \leftrightarrow y = \overline{x + y} = x + y + 1$$
$$x \mid y = \overline{xy} = xy + 1$$
$$x \downarrow y = \overline{x \lor y} = (x \lor y) + 1 = xy + x + y + 1$$

### <span style="color: #D58EAD;">Пример 1. Метод неопределённых коэффициентов</span>

Дано:

| $x$ | $y$ | $f$ |
|---|---|---|
| 0 | 0 | 1 |
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| 1 | 1 | 1 |

**Решение**

Ищем $f = a_{00} + a_{01}y + a_{10}x + a_{11}xy$. Подставляя наборы, получаем:

$$f = 1 + (0 + 1)y + (1 + 1)x + (1 + 1 + 0 + 1)xy = \boxed{1 + y + xy}$$

### <span style="color: #D58EAD;">Пример 2. Метод треугольника (по вектору значений)</span>

Дано (та же функция): вектор значений $f = (1\ 0\ 1\ 1)$

**Решение**

Складываем соседние значения по модулю 2, спускаясь треугольником:

$$1\ \underline{1}\ 0\ \underline{1}\ 1 \ \Rightarrow\ 1 + y + xy$$

Левый столбец треугольника даёт коэффициенты: $1$ (свободный член), $1$ (при $y$), $0$ (при $x$), $1$ (при $xy$)

### <span style="color: #D58EAD;">Пример 3. Через СДНФ</span>

Дано (та же функция)

**Решение**

$$\bar x \bar y \lor x \bar y \lor xy = \bar x \bar y + x\bar y + xy = (x + 1)(y + 1) + x(y + 1) + xy = \boxed{1 + y + xy}$$

### <span style="color: #D58EAD;">Пример 4. Разложение по переменным</span>

Дано: $f = (1\ 1\ 1\ 1\ 1\ 1\ 0\ 1)$

**Решение**

Разбиваем вектор пополам: $x = 0$ даёт $(1\ 1\ 1\ 1)$, $x = 1$ даёт $(1\ 1\ 0\ 1)$:

$$f = \bar x\,(1\ 1\ 1\ 1) + x\,(1\ 1\ 0\ 1) = \bar x + x(y \to z) = x + 1 + x(yz + y + 1) = \boxed{1 + xy + xyz}$$
