## <span style="color: #D58EAD;">1. Литералы</span>

> <span style="color: #D58EAD;">Литерал</span> - любая переменная $x$ или её отрицание $\bar x$

Вводится обозначение:

$$x^\sigma = \begin{cases} x, & \text{если } \sigma = 1 \\ \bar x, & \text{если } \sigma = 0 \end{cases}$$

Свойства:

$$\sigma^\sigma = 1 \quad \text{и} \quad \sigma^{\bar\sigma} = 0 \quad \text{для всех } \sigma \in B$$

$$x^\sigma = 1 \ \Leftrightarrow\ x = \sigma$$
$$x^\sigma = 0 \ \Leftrightarrow\ x = \bar\sigma$$

---

## <span style="color: #D58EAD;">2. Элементарные конъюнкты. Полные элементарные конъюнкты</span>

> <span style="color: #D58EAD;">Элементарный конъюнкт</span> - конъюнкция литералов
> $$x_{i_1}^{\sigma_1} \ \&\ x_{i_2}^{\sigma_2} \ \&\ \ldots \ \&\ x_{i_k}^{\sigma_k},$$
> в которой <span style="color: #AE91CE;">каждая</span> переменная входит <span style="color: #AE91CE;">не более одного</span> раза

Пример: $x_2 \land \bar x_4$

> Элементарный конъюнкт называется <span style="color: #D58EAD;">полным</span>, если он содержит <span style="color: #AE91CE;">все</span> рассматриваемые переменные

---

## <span style="color: #D58EAD;">3. ДНФ и СДНФ</span>

> <span style="color: #D58EAD;">ДНФ</span> (дизъюнктивная нормальная форма) - дизъюнкция элементарных конъюнктов

Пример: $x_2\bar x_4 \lor \bar x_1 \lor x_2 \lor x_3$

> <span style="color: #D58EAD;">СДНФ</span> (совершенная ДНФ) - дизъюнкция <span style="color: #D58EAD;">полных</span> элементарных конъюнктов

---

## <span style="color: #D58EAD;">4. Теорема о существовании СДНФ</span>

> **Теорема.** Для любой булевой функции $f: B^n \to B$ имеет место
> $$f(x_1, x_2, \ldots, x_n) = \bigvee_{(\sigma_1, \sigma_2, \ldots, \sigma_n) \in I} x_1^{\sigma_1} \ \&\ x_2^{\sigma_2} \ \&\ \ldots \ \&\ x_n^{\sigma_n},$$
> где $I = \{\,(\sigma_1, \sigma_2, \ldots, \sigma_n) \in B^n \mid f(\sigma_1, \sigma_2, \ldots, \sigma_n) = 1\,\}$

**Доказательство**

Пусть $f(x_1, x_2, \ldots, x_n) = 1$. Тогда при $\sigma_1 = x_1$, $\sigma_2 = x_2$, $\ldots$, $\sigma_n = x_n$ имеем

$$x_1^{\sigma_1} \ \&\ x_2^{\sigma_2} \ \&\ \ldots \ \&\ x_n^{\sigma_n} = 1 \ \&\ 1 \ \&\ \ldots \ \&\ 1 = 1$$

Поэтому правая часть <span style="color: #8FBF8F;">равна</span> $1$

Пусть правая часть равна $1$. Тогда для некоторого $(\sigma_1, \sigma_2, \ldots, \sigma_n) \in B^n$:

$$f(\sigma_1, \sigma_2, \ldots, \sigma_n) = 1 \quad \text{и} \quad x_1^{\sigma_1} \ \&\ x_2^{\sigma_2} \ \&\ \ldots \ \&\ x_n^{\sigma_n} = 1$$

Значит, для каждого $i = \overline{1, n}$ значение $x_i^{\sigma_i} = 1$, а это возможно только при $\sigma_i = x_i$. Таким образом, $f(x_1, x_2, \ldots, x_n) = 1$

Поэтому левая часть <span style="color: #8FBF8F;">равна</span> $1$ $\blacksquare$

## <span style="color: #D58EAD;">5. Элементарные дизъюнкты. Полные элементарные дизъюнкты</span>

> <span style="color: #D58EAD;">Элементарный дизъюнкт</span> - дизъюнкция литералов
> $$x_{i_1}^{\sigma_1} \lor x_{i_2}^{\sigma_2} \lor \ldots \lor x_{i_k}^{\sigma_k},$$
> в которой <span style="color: #AE91CE;">каждая</span> переменная входит <span style="color: #AE91CE;">не более одного</span> раза

Пример: $x_2 \lor \bar x_4$

> Элементарный дизъюнкт называется <span style="color: #D58EAD;">полным</span>, если он содержит <span style="color: #AE91CE;">все</span> рассматриваемые переменные

---

## <span style="color: #D58EAD;">6. КНФ и СКНФ</span>

> <span style="color: #D58EAD;">КНФ</span> (конъюнктивная нормальная форма) - конъюнкция нескольких элементарных дизъюнктов

Пример: $(x_2 \lor \bar x_4)\,(\bar x_1 \lor x_2 \lor x_3)$

> <span style="color: #D58EAD;">СКНФ</span> (совершенная КНФ) - конъюнкция нескольких <span style="color: #D58EAD;">полных</span> элементарных дизъюнктов

---

## <span style="color: #D58EAD;">7. Теорема о существовании СКНФ</span>

> **Теорема.** Для любой булевой функции $f: B^n \to B$ имеет место
> $$f(x_1, x_2, \ldots, x_n) = \mathop{\&}_{(\sigma_1, \sigma_2, \ldots, \sigma_n) \in J} \left( x_1^{\bar\sigma_1} \lor x_2^{\bar\sigma_2} \lor \ldots \lor x_n^{\bar\sigma_n} \right),$$
> где $J = \{\,(\sigma_1, \sigma_2, \ldots, \sigma_n) \in B^n \mid f(\sigma_1, \sigma_2, \ldots, \sigma_n) = 0\,\}$

**Доказательство**

Пусть $f(x_1, x_2, \ldots, x_n) = 0$. Тогда при $\sigma_1 = x_1$, $\sigma_2 = x_2$, $\ldots$, $\sigma_n = x_n$ имеем

$$x_1^{\bar\sigma_1} \lor x_2^{\bar\sigma_2} \lor \ldots \lor x_n^{\bar\sigma_n} = 0 \lor 0 \lor \ldots \lor 0 = 0$$

Поэтому правая часть <span style="color: #8FBF8F;">равна</span> $0$

Пусть правая часть равна $0$. Тогда для некоторого $(\sigma_1, \sigma_2, \ldots, \sigma_n) \in B^n$:

$$f(\sigma_1, \sigma_2, \ldots, \sigma_n) = 0 \quad \text{и} \quad x_1^{\bar\sigma_1} \lor x_2^{\bar\sigma_2} \lor \ldots \lor x_n^{\bar\sigma_n} = 0$$

Значит, для каждого $i = \overline{1, n}$ значение $x_i^{\bar\sigma_i} = 0$, а это возможно только при $\bar\sigma_i = \bar x_i$, то есть $\sigma_i = x_i$. Таким образом, $f(x_1, x_2, \ldots, x_n) = 0$

Поэтому левая часть <span style="color: #8FBF8F;">равна</span> $0$ $\blacksquare$

---

## <span style="color: #D58EAD;">8. Единственность СДНФ и СКНФ</span>

> **Теорема.** Для любой булевой функции $f: B^n \to B$ существует <span style="color: #AE91CE;">одна</span> СДНФ и <span style="color: #AE91CE;">одна</span> СКНФ с точностью до перестановок в конъюнкциях и дизъюнкциях

**Доказательство**

С точностью до перестановок существует ровно $2^n$ полных элементарных конъюнктов/дизъюнктов. Поэтому с точностью до перестановок существует ровно $2^{2^n}$ различных СДНФ/СКНФ. Но всего имеется ровно столько же - $2^{2^n}$ - булевых функций $f: B^n \to B$, причём у <span style="color: #AE91CE;">каждой</span> существует <span style="color: #AE91CE;">по крайней мере одна</span> СДНФ/СКНФ. Значит, у каждой функции имеется <span style="color: #8FBF8F;">ровно одна</span> СДНФ/СКНФ $\blacksquare$
