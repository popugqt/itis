## <span style="color: #D58EAD;">1. Линейные функции и их композиции</span>

> Функция $f$ называется <span style="color: #D58EAD;">линейной</span>, если её многочлен Жегалкина <span style="color: #e0313a;">не содержит конъюнкций</span>:
> $$f(x_1 \ldots x_n) = a_0 + a_1 x_1 + a_2 x_2 + \ldots + a_n x_n$$

Примеры:

| Функция | Многочлен Жегалкина | Линейна? |
|---|---|---|
| $\bar x$ | $x + 1$ | <span style="color: #8FBF8F;">линейная</span> |
| $x \leftrightarrow y$ | $x + y + 1$ | <span style="color: #8FBF8F;">линейная</span> |
| $x \lor y$ | $xy + x + y$ | <span style="color: #e0313a;">не линейная</span> |
| $xy$ | $xy$ | <span style="color: #e0313a;">не линейная</span> |

> **Теорема (композиция линейных функций).** Если $f, g_1 \ldots g_n$ - линейные функции, то
> $$h(x_1 \ldots x_n) = f(g_1(x_1 \ldots x_n) \ldots g_n(x_1 \ldots x_n))$$
> - <span style="color: #8FBF8F;">линейная функция</span>

**Доказательство**

Запишем линейные функции в векторном виде:

$$g_i(x_1 \ldots x_n) = (x_1 \ldots x_n) \cdot \begin{pmatrix} b_1^i \\ \vdots \\ b_m^i \end{pmatrix} + b_0^i = \vec x\, \vec b^i + b_0^i$$

$$f(y_1 \ldots y_n) = (y_1 \ldots y_n) \cdot \begin{pmatrix} a_1 \\ \vdots \\ a_m \end{pmatrix} + a_0 = (y_1 \ldots y_n)\,\vec a + a_0$$

Тогда

$$h(x_1 \ldots x_n) = (g_1(x_1 \ldots x_n) \ldots g_n(x_1 \ldots x_n))\,\vec a + a_0 = (\vec x\,\vec b^1 + b_0^1,\ \vec x\,\vec b^2 + b_0^2,\ \ldots,\ \vec x\,\vec b^n + b_0^n)\,\vec a + a_0 =$$

$$= \left(\vec x\,(\vec b^1, \vec b^2, \ldots, \vec b^n) + (b_0^1, \ldots, b_0^n)\right)\vec a + a_0 = \vec x\,(B\vec a) + (\vec b\,\vec a) + a_0$$

- снова линейная функция $\blacksquare$

> **Следствие.** $xy$, $x \lor y$, $x \to y$ <span style="color: #e0313a;">не выражаются</span> через $\{\oplus, 1\}$

## <span style="color: #D58EAD;">2. Лемма о нелинейной функции</span>

> **Лемма.** Если $f \notin L$, то $\& \in [f, 0, 1, \neg]$

**Доказательство**

$f(x_1 \ldots x_n) = \sum_{i=1}^{n} K_i$, $\exists K_i$ длины $\ge 2$. <span style="color: #AE91CE;">Выберем</span> $K_i$ длины $\ge 2$ <span style="color: #AE91CE;">минимальной</span> длины: $K_i = x_1 \cdot x_2 \cdot \ldots \cdot x_m$, $m \le n$. Тогда

$$f(x_1, x_2, \underbrace{1 \ldots 1}_{}, 0 \ldots 0) = x_1 x_2 + \sum_{\text{длина } K_j < 2} K_j + \sum_{\substack{\text{длина } K_i > 2 \\ i \ne j}} K_i = x_1 x_2 + \alpha x_1 + \beta x_2 + \gamma = (x_1 + \beta)(x_2 + \alpha) + \delta$$

При подстановке слагаемые длины $> 2$ <span style="color: #AE91CE;">обнуляются</span>. Далее:

$$\delta + f_c(x_1, x_2, 1 \ldots 1, 0 \ldots 0) = (x_1 + \beta)(x_2 + \alpha)$$

$$xy = \delta + f_c(x + \beta,\ y + \alpha,\ 1 \ldots 1,\ 0 \ldots 0) = xy$$

Здесь использованы соотношения $x + 0 = x$, $y + 0 = y$, $x + 1 = \bar x$, $y + 1 = \bar y$

$\Rightarrow h(x) \in [f_L, 0, 1, \neg]$ $\blacksquare$

## <span style="color: #D58EAD;">3. Самодвойственные функции и их композиции</span>

> <span style="color: #D58EAD;">Двойственной функцией</span> к $f$ называется функция, которая получается как
> $$f^*(x_1 \ldots x_n) = \overline{f(\bar x_1 \ldots \bar x_n)}$$

> **Теорема.** Если $h(x_1 \ldots x_n) = f(g_1(x_1 \ldots x_n) \ldots g_n(x_1 \ldots x_n))$, то
> $$h^*(x_1 \ldots x_n) = f^*(g_1^*(x_1 \ldots x_n) \ldots g_n^*(x_1 \ldots x_n))$$

**Доказательство**

$$h^*(x_1 \ldots x_n) = \overline{h(\bar x_1 \ldots \bar x_n)} = \overline{f\left(\overline{g_1(\bar x_1 \ldots \bar x_n)} \ldots \overline{g_n(\bar x_1 \ldots \bar x_n)}\right)} = f^*(g_1^*(x_1 \ldots x_n) \ldots g_n^*(x_1 \ldots x_n))\ \blacksquare$$

> Функция $f$ называется <span style="color: #D58EAD;">самодвойственной</span>, если $f^* = f$:
> $$\overline{f(\bar x_1 \ldots \bar x_n)} = f(x_1 \ldots x_n)$$

**Следствие:** класс $S$ <span style="color: #8FBF8F;">замкнут</span>

Примеры самодвойственных функций:

- $f(x) = x$
- $f(x) = \bar x$
- $f(x, y, z) = x + y + z$
- $f(x, y, z) = xy \lor yz \lor xz$ - <span style="color: #D58EAD;">функция голосования</span>

---

## <span style="color: #D58EAD;">4. Лемма о несамодвойственной функции</span>

> **Лемма.** Если $f_S \notin S$, то $0, 1 \in [f_S, \neg]$

**Доказательство**

Пусть $f \notin S$. Тогда $\exists (x_1 \ldots x_n)$:

$$\overline{f(\bar x_1 \ldots \bar x_n)} = f^*(x_1 \ldots x_n) \ne f(x_1 \ldots x_n)$$

Тогда $f(\bar x_1 \ldots \bar x_n) = f(x_1 \ldots x_n)$. Положим

$$g_i(x) = \begin{cases} x, & \text{если } x_i = 1 \\ \bar x, & \text{если } x_i = 0 \end{cases} \qquad g_i(0) = \bar x_i,\quad g_i(1) = x_i$$

$$h(x) = f_S(g_1(x) \ldots g_n(x))$$
$$h(0) = f_S(g_1(0) \ldots g_n(0)) = f_S(\bar x_1 \ldots \bar x_n)$$
$$h(1) = f_S(g_1(1) \ldots g_n(1)) = f_S(x_1 \ldots x_n)$$

$\Rightarrow h(0) = h(1)$ $\Rightarrow$ $\overline{h(x)} = 0, 1 \in [f_S, \neg]$ $\blacksquare$

## <span style="color: #D58EAD;">5. Монотонные функции и их композиции</span>

> <span style="color: #D58EAD;">Монотонной функцией</span> называется функция $f$, если
> $$x_1 \le y_1,\ x_2 \le y_2,\ \ldots,\ x_n \le y_n \ \Rightarrow\ f(x_1 \ldots x_n) \le f(y_1 \ldots y_n)$$

**Следствие:** класс $M$ <span style="color: #8FBF8F;">замкнут</span>

> **Теорема.** Если $f(x_1 \ldots x_n)$, $g_1(x_1 \ldots x_n) \ldots g_m(x_1 \ldots x_n)$ - монотонные функции, то
> $$f(g_1(x_1 \ldots x_n) \ldots g_m(x_1 \ldots x_n))$$
> - <span style="color: #8FBF8F;">монотонная функция</span>

**Доказательство**

Пусть $h(x_1 \ldots x_n) = f(g_1(x_1 \ldots x_n) \ldots g_m(x_1 \ldots x_n))$. Если $(x_1 \ldots x_n) \le (y_1 \ldots y_n)$, то

$$g_1(x_1 \ldots x_n) \le g_1(y_1 \ldots y_n), \quad \ldots, \quad g_m(x_1 \ldots x_n) \le g_m(y_1 \ldots y_n)$$

Пусть $g_1(\vec x) \le g_1(\vec y)$, $\ldots$, $g_m(\vec x) \le g_m(\vec y)$. Тогда

$$(g_1(\vec x) \ldots g_m(\vec x)) \le (g_1(\vec y) \ldots g_m(\vec y))$$

Тогда $f(g_1(\vec x) \ldots g_m(\vec x)) \le f(g_1(\vec y) \ldots g_m(\vec y))$

$\Rightarrow h(\vec x) \le h(\vec y)$ $\Rightarrow$ $h$ - <span style="color: #8FBF8F;">монотонная</span> $\blacksquare$

$$[\{0, 1, \land, \lor\}] \subseteq M$$

> **Теорема.** Простые импликанты монотонной функции <span style="color: #e0313a;">не содержат отрицаний</span>

**Доказательство**

Пусть $K$ - простой импликант монотонной функции $f$, $K = \bar x_1\, x_2^{\sigma_2} \ldots x_k^{\sigma_k}$

$$K(0, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n) = 1, \quad \text{где } \alpha_{k+1} \ldots \alpha_n \in \{0; 1\}$$
$$f(0, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n) = 1$$

Но $(0, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n) \le (1, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n)$, поэтому

$$f(0, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n) \le f(1, \sigma_2 \ldots \sigma_k, \alpha_{k+1} \ldots \alpha_n) = 1$$

Тогда $K' = x_2^{\sigma_2} \ldots x_k^{\sigma_k}$: $K' = 1 \Leftrightarrow$ на наборе $(\alpha_1, \sigma_2 \ldots \sigma_n, \alpha_{k+1} \ldots \alpha_n)$

$\Downarrow$

$f(\alpha_1, \sigma_2 \ldots \sigma_n, \alpha_{k+1} \ldots \alpha_n) = 1$ $\Rightarrow$ $K'$ - <span style="color: #8FBF8F;">импликант</span>

Но это <span style="color: #e0313a;">противоречие</span>: $K$ - простой импликант $\blacksquare$

**Следствия:**

0. Класс $M$ - замкнут
1. Сокращённая ДНФ монотонной функции <span style="color: #e0313a;">не содержит отрицаний</span>
2. Функция монотонная $\Leftrightarrow$ функцию можно представить в виде суперпозиции функций $\land$, $\lor$, $0$, $1$

$$M = [\{0, 1, \land, \lor\}]$$

**Доказательство:** из первой теоремы $[\{0, 1, \land, \lor\}] \subseteq M$; из теоремы о сокращённой ДНФ $M \subseteq [\{0, 1, \land, \lor\}]$

> **Теорема.** Сокращённая ДНФ монотонной функции является её <span style="color: #AE91CE;">единственной</span> $\Rightarrow$ <span style="color: #AE91CE;">единственной</span> минимальной

**Доказательство**

$f = \bigvee_{i=1}^{m} K_i$ - сокращённая ДНФ. Рассмотрим $K_1$: $f = K_1 \lor f'$, где $f' = \bigvee_{i=2}^{m} K_i$. Нужно доказать $f \ne f'$

В каждом $K_i$ ($i \ge 2$) существует <span style="color: #AE91CE;">хотя бы одна</span> переменная $x_j$ ($j > l$). Поставим $K_1$, $f$, $f'$ на наборе $(\underbrace{1 \ldots 1}_{l}, 0 \ldots 0)$:

$$K_1(1 \ldots 1, 0 \ldots 0) = 1$$
$$f(1 \ldots 1, 0 \ldots 0) = 1$$
$$f'(1 \ldots 1, 0 \ldots 0) = 0$$

$\Rightarrow f \ne f'$ $\blacksquare$

## <span style="color: #D58EAD;">6. Лемма о немонотонной функции</span>

> **Лемма.** Если $f_M \notin M$, то $\neg \in [f_M, 0, 1]$

**Доказательство**

$$g_i(x) = \begin{cases} 0, & \text{если } x_i = y_i = 0 \\ 1, & \text{если } x_i = y_i = 1 \\ x, & \text{если } x_i = 0,\ y_i = 1 \end{cases} \qquad g_i(0) = x_i,\quad g_i(1) = y_i$$

$$h(x) = f_M(g_1(x) \ldots g_n(x))$$
$$h(0) = f_M(g_1(0) \ldots g_n(0)) = f_M(x_1 \ldots x_n) = 1$$
$$h(1) = f_M(g_1(1) \ldots g_n(1)) = f_M(y_1 \ldots y_n) = 0$$

$\Rightarrow h(x)$ и есть $\neg \in [f_M, 0, 1]$ $\blacksquare$

Здесь $(x_1 \ldots x_n) \le (y_1 \ldots y_n)$, но $f_M(x_1 \ldots x_n) = 1 > f_M(y_1 \ldots y_n) = 0$ - такая пара наборов существует, так как $f_M$ <span style="color: #e0313a;">немонотонная</span>
