# <span style="background-color: rgba(213, 142, 173, 0.30);">Полнота системы булевых функций и поиск базисов</span>

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">1. Теорема Поста</span>

**<span style="color: #D58EAD;">Система булевых функций</span>** $F$ функционально полна тогда и только тогда, когда она целиком не содержится ни в одном из пяти классов:

$$T_0,\quad T_1,\quad S,\quad L,\quad M.$$

Для практической проверки это означает: в каждом из пяти столбцов таблицы принадлежности должен быть хотя бы один знак `−`.

- Если во <span style="color: #AE91CE;">всех пяти</span> столбцах есть хотя бы один `−`, система <span style="color: #8FBF8F;">полная</span>.
- Если хотя бы один столбец целиком состоит из `+`, система <span style="color: #e0313a;">неполная</span>.

Почему так: наличие `−` в столбце означает, что хотя бы одна функция системы не принадлежит соответствующему классу Поста.

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">2. Пример проверки полноты</span>

Допустим, после проверки функций получена таблица:

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $f_1$ | − | + | − | + | + |
| $f_2$ | + | − | − | + | − |
| $f_3$ | + | + | − | − | + |
| $f_4$ | + | + | − | − | + |

<span style="color: #AE91CE;">Проверим</span> каждый столбец:

- $T_0$: есть `−` у $f_1$;
- $T_1$: есть `−` у $f_2$;
- $S$: есть `−` у $f_1$, $f_2$, $f_3$ и $f_4$;
- $L$: есть `−` у $f_3$ и $f_4$;
- $M$: есть `−` у $f_2$.

Во <span style="color: #AE91CE;">всех пяти</span> столбцах есть хотя бы один минус. Следовательно:

$$\boxed{F\text{ — полная система}}$$

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">3. Что такое базис</span>

> **<span style="color: #D58EAD;">Базис</span>** — минимальная по включению полная подсистема.

Это означает:

1. сама подсистема полна;
2. если удалить из неё любую одну функцию, полнота потеряется.

> **<span style="background-color: rgba(224, 108, 117, 0.28);">Важно!</span>**
> Минимальная по включению подсистема не обязательно имеет наименьшее число функций среди всех возможных вариантов. Для поиска всех базисов нужно найти все полные подсистемы, из которых уже нельзя удалить функцию, сохранив полноту.

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">4. Удобный способ поиска базисов</span>

Для <span style="color: #AE91CE;">каждой</span> функции <span style="color: #AE91CE;">выпиши</span> классы, которые она нарушает, то есть столбцы, в которых у неё стоит `−`.

Для таблицы выше:

| Функция | Какие классы нарушает |
| --- | --- |
| $f_1$ | $T_0, S$ |
| $f_2$ | $T_1, S, M$ |
| $f_3$ | $S, L$ |
| $f_4$ | $S, L$ |

Полная подсистема должна нарушать все пять классов:

$$\{T_0,T_1,S,L,M\}.$$

> Другими словами, объединение множеств нарушаемых классов выбранных функций должно содержать все пять классов.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Шаг 1. Находим обязательные функции</span>

- Только $f_1$ нарушает $T_0$. Поэтому $f_1$ обязательно входит в каждый базис.
- Только $f_2$ нарушает $T_1$ и $M$. Поэтому $f_2$ обязательно входит в каждый базис.
- Класс $L$ нарушает $f_3$ или $f_4$. Поэтому нужна хотя бы одна из этих функций.
- Класс $S$ уже нарушается функциями $f_1$ и $f_2$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Шаг 2. Перебираем варианты</span>

$f_1$ и $f_2$ обязательны. Чтобы в столбце $L$ остался минус, добавляем $f_3$ или $f_4$.

Получаем два кандидата:

$$B_1=\{f_1,f_2,f_3\},$$

$$B_2=\{f_1,f_2,f_4\}.$$

### <span style="background-color: rgba(213, 142, 173, 0.30);">Шаг 3. Проверяем полноту и минимальность каждого кандидата</span>

Для $B_1$:

- $T_0$ нарушает $f_1$;
- $T_1$ нарушает $f_2$;
- $S$ нарушают $f_1$ и $f_2$;
- $L$ нарушает $f_3$;
- $M$ нарушает $f_2$.

Все пять классов нарушены — $B_1$ полна.

<span style="color: #AE91CE;">Проверяем</span> удаление каждой функции:

- удаляем $f_1$ — в столбце $T_0$ больше нет минуса;
- удаляем $f_2$ — в столбцах $T_1$ и $M$ больше нет минусов;
- удаляем $f_3$ — в столбце $L$ больше нет минуса.

Удалить ни одну функцию <span style="color: #e0313a;">нельзя</span>. Значит, $B_1$ — базис.

Для $B_2$ рассуждение такое же: $f_4$ вместо $f_3$ обеспечивает минус в столбце $L$. Удаление любой функции также разрушает полноту. Значит, $B_2$ — базис.

Итог:

$$\boxed{B_1=\{f_1,f_2,f_3\},\qquad B_2=\{f_1,f_2,f_4\}}$$

Других базисов нет: $f_1$ и $f_2$ обязательны, а для столбца $L$ можно выбрать только $f_3$ или $f_4$.

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">5. Как найти все базисы, если функций много</span>

> Если функций $m$, существует $2^m$ подмножеств. Можно проверять их перебором.

Для каждого подмножества:

1. <span style="color: #AE91CE;">Проверь</span>, есть ли в каждом из пяти столбцов хотя бы один `−`.
2. Если нет — это подмножество неполное, его исключаем.
3. Если да — <span style="color: #AE91CE;">попробуй удалить</span> из него каждую функцию по очереди.
4. Если после удаления любой функции полнота теряется, подмножество <span style="color: #8FBF8F;">является базисом</span>.
5. Если после удаления хотя бы одной функции полнота сохраняется, это подмножество <span style="color: #e0313a;">не является базисом</span>.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Быстрая проверка по столбцам</span>

> Если в каком-то столбце ровно один минус, соответствующая функция обязательна.
> 
> Если в столбце несколько минусов, достаточно выбрать хотя бы одну функцию из этого набора. Но выбор может зависеть от других столбцов: одна функция может одновременно нарушать несколько классов.
> 
> <span style="color: #e0313a;">Нельзя</span> просто выбрать по одной функции из каждого столбца, не проверив остальные столбцы и минимальность выбранного набора.

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">6. Универсальный алгоритм для контрольной</span>

1. Сначала проверь полноту всей системы.
2. Если система неполная, базисов полной системы в ней нет.
3. Запиши для каждой функции множество нарушаемых классов.
4. Найди обязательные функции по столбцам с единственным минусом.
5. Перебери варианты для остальных столбцов.
6. Для каждого полного варианта проверь удаление каждой функции.
7. Запиши все варианты, которые полны и теряют полноту после удаления любой функции.

Не забывай: в таблице классов Поста каждый знак нужно обосновать отдельно. Подробный порядок проверки находится в файле [[Классы Поста]].
