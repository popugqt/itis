# <span style="background-color: rgba(213, 142, 173, 0.30);">Классы Поста: проверка с обоснованием каждого знака</span>

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">1. Что означает каждый класс</span>

### Класс $T_0$ - сохранение нуля

Функция сохраняет 0, если на нулевом наборе она равна 0:

$$f(0,0,\ldots,0)=0.$$

При стандартном порядке наборов это <span style="color: #AE91CE;">первый элемент</span> вектора.

- Первый элемент равен 0 - ставим `+`.
- Первый элемент равен 1 - ставим `−`, потому что условие не выполнено.

### Класс $T_1$ - сохранение единицы

Функция сохраняет 1, если на единичном наборе она равна 1:

$$f(1,1,\ldots,1)=1.$$

При стандартном порядке это <span style="color: #AE91CE;">последний элемент</span> вектора.

- Последний элемент равен 1 - ставим `+`.
- Последний элемент равен 0 - ставим `−`.

### Класс $S$ - самодвойственность

Функция самодвойственна, если на противоположных наборах её значения противоположны:

$$f(x_1,\ldots,x_n)=\neg f(\neg x_1,\ldots,\neg x_n).$$

То же самое можно записать так:

$$f(x)\ne f(\neg x).$$

Нужно <span style="color: #AE91CE;">сравнивать</span> пары наборов, где все нули заменены единицами, а все единицы - нулями.

- Во <span style="color: #AE91CE;">всех</span> противоположных парах ответы <span style="color: #8FBF8F;">разные</span> - ставим `+`.
- Хотя бы в <span style="color: #AE91CE;">одной</span> паре ответы <span style="color: #e0313a;">одинаковые</span> - ставим `−`.

Для знака `+` необходимо проверить все пары. Для знака `−` достаточно привести одну пару с одинаковыми значениями.

### Класс $L$ - линейные функции

Функция принадлежит $L$, если её полином Жегалкина имеет степень не выше 1:

$$f=a_0\oplus a_1x_1\oplus\cdots\oplus a_nx_n.$$

Свободный член разрешён. Произведений нескольких переменных быть не должно.

- Нет произведений переменных - `+`.
- Есть хотя бы один член степени 2 или выше - `−`.

### Класс $M$ - монотонные функции

> Функция монотонна, если увеличение входных значений не приводит к уменьшению результата.

Если из набора $x$ получить набор $y$, заменив один или несколько нулей на единицы, должно выполняться:

$$f(x)\le f(y).$$

На практике достаточно проверить все переходы, которые отличаются ровно одной координатой. Если каждый такой переход не уменьшает значение функции, то и любой переход с заменой нескольких нулей на единицы не уменьшит результат.

- Все переходы `0 → 1` на входе сохраняют или увеличивают выход - `+`.
- Нашёлся переход, где выход изменился `1 → 0`, - `−`.

## <span style="background-color: rgba(213, 142, 173, 0.30);">2. Подробная проверка на векторе из образца</span>

Пусть дана функция:

$$f_2=(1001100101100110).$$

Порядок наборов - от `0000` до `1111`.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Проверка</span> $T_0$

Первый символ вектора равен 1. Значит:

$$f_2(0000)=1\ne0.$$

Функция не сохраняет 0:

$$\boxed{f_2\notin T_0}$$

В таблице ставим `−` в столбце $T_0$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Проверка</span> $T_1$

Последний символ вектора равен 0. Значит:

$$f_2(1111)=0\ne1.$$

Функция не сохраняет 1:

$$\boxed{f_2\notin T_1}$$

В таблице ставим `−` в столбце $T_1$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Проверка</span> $S$

Для <span style="color: #AE91CE;">четырёх</span> переменных есть <span style="color: #AE91CE;">восемь</span> пар противоположных наборов. В таблице достаточно записать каждую пару один раз:

| Первый набор | Противоположный набор | $f_2$ на первом | $f_2$ на втором | Значения разные? |
| --- | --- | ---: | ---: | --- |
| `0000` | `1111` | 1 | 0 | Да |
| `0001` | `1110` | 0 | 1 | Да |
| `0010` | `1101` | 0 | 1 | Да |
| `0011` | `1100` | 1 | 0 | Да |
| `0100` | `1011` | 1 | 0 | Да |
| `0101` | `1010` | 0 | 1 | Да |
| `0110` | `1001` | 0 | 1 | Да |
| `0111` | `1000` | 1 | 0 | Да |

Во всех восьми парах значения разные. Следовательно:

$$\boxed{f_2\in S}$$

В таблице ставим `+` в столбце $S$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Проверка</span> $L$

Полином Жегалкина для этого вектора:

$$f_2=1\oplus x_1\oplus x_3\oplus x_4.$$

В нём нет произведений переменных, степень не выше 1. Поэтому:

$$\boxed{f_2\in L}$$

В таблице ставим `+` в столбце $L$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Проверка</span> $M$

Для монотонности при увеличении входа выход не должен уменьшаться.

<span style="color: #AE91CE;">Возьмём</span> два набора, которые отличаются только первой координатой:

$$0000\le1000.$$

По вектору:

$$f_2(0000)=1,\qquad f_2(1000)=0.$$

Вход увеличился, а выход изменился с 1 на 0. Условие монотонности нарушено:

$$\boxed{f_2\notin M}$$

В таблице ставим `−` в столбце $M$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Итоговая строка таблицы</span>

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $f_2$ | − | − | + | + | − |

Каждый знак обоснован: для `−` приведено нарушение условия, для `+` выполнена полная проверка критерия.

## <span style="background-color: rgba(213, 142, 173, 0.30);">3. Как полностью проверять монотонность</span>

Для $n$ переменных нужно проверить переходы, в которых меняется ровно одна координата с 0 на 1.

Количество таких переходов равно:

$$n\cdot2^{n-1}.$$

Для четырёх переменных это:

$$4\cdot2^3=32\text{ перехода}.$$

Почему именно столько: можно выбрать одну из четырёх координат, а остальные три координаты могут быть любыми. Каждая пара учитывается один раз - от меньшего набора к большему.

Порядок проверки:

1. <span style="color: #AE91CE;">Выбери</span> переменную, которую меняешь.
2. <span style="color: #AE91CE;">Найди</span> все наборы, где эта переменная равна 0.
3. Для каждого такого набора <span style="color: #AE91CE;">сравни</span> значение функции до и после замены 0 на 1.
4. <span style="color: #AE91CE;">Повтори</span> для каждой переменной.

Пример для $g(x_1,x_2)=x_1\land x_2$:

| Переход | Значения функции | Условие выполнено? |
| --- | --- | --- |
| `00 → 10` | $0\to0$ | Да |
| `00 → 01` | $0\to0$ | Да |
| `01 → 11` | $0\to1$ | Да |
| `10 → 11` | $0\to1$ | Да |

Все четыре перехода проверены, ни один не уменьшает значение. Следовательно, $g\in M$.

Для доказательства немонотонности достаточно одного плохого перехода. Для доказательства монотонности нужно проверить все переходы.

## <span style="background-color: rgba(213, 142, 173, 0.30);">4. Как обосновать знаки в таблице</span>

| Класс | Что написать для `+` | Что написать для `−` |
| --- | --- | --- |
| $T_0$ | $f(00\ldots0)=0$ | $f(00\ldots0)=1$ |
| $T_1$ | $f(11\ldots1)=1$ | $f(11\ldots1)=0$ |
| $S$ | Перечислить все противоположные пары и показать, что значения в каждой паре разные | Привести одну пару, где значения одинаковые |
| $L$ | Выписать полином Жегалкина и показать, что степень не выше 1 | Показать член степени 2 или выше |
| $M$ | Проверить все переходы по одной координате `0 → 1` | Привести один переход, где выход меняется `1 → 0` |

Не пиши просто «функция принадлежит классу». Покажи, что именно проверялось.
