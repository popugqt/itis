# <span style="color: #D58EAD;">Сокращённая, тупиковые и минимальные ДНФ</span>

---

## <span style="color: #D58EAD;">1. Основные определения</span>

<span style="color: #D58EAD;">СДНФ</span> - дизъюнкция минтермов (элементарных конъюнкций) для всех наборов, на которых функция равна 1. В каждом минтерме присутствуют все переменные: сама переменная или её отрицание.

<span style="color: #D58EAD;">Простая импликанта</span> - импликанта, из которой <span style="color: #e0313a;">нельзя</span> убрать литерал, не захватив набор, где функция равна 0.

<span style="color: #D58EAD;">Сокращённая ДНФ</span> - дизъюнкция <span style="color: #AE91CE;">всех</span> простых импликант функции.

<span style="color: #D58EAD;">Тупиковая ДНФ</span> - ДНФ, в которой:

- каждое слагаемое является простой импликантой;
- <span style="color: #AE91CE;">все</span> единичные наборы функции покрыты;
- <span style="color: #e0313a;">нельзя</span> удалить ни одно слагаемое, не изменив функцию.

<span style="color: #D58EAD;">Минимальная ДНФ</span> - тупиковая ДНФ с наименьшей сложностью по принятому критерию. Обычно считают <span style="color: #AE91CE;">общее количество литералов</span> во всех слагаемых. Иногда дополнительно сравнивают количество слагаемых - уточняй критерий преподавателя.

У одной функции может быть несколько тупиковых и несколько минимальных ДНФ.

---

## <span style="color: #D58EAD;">2. Метод склеивания</span>

Пусть дана функция:

$$f=(0000111101010100).$$

Используем порядок наборов от `0000` до `1111`.

### <span style="color: #D58EAD;">Шаг 1. Выписываем единичные наборы</span>

<span style="color: #AE91CE;">Разобьём</span> вектор по наборам:

|                  Набор                  |                \(f\)                 |
| :-------------------------------------: | :----------------------------------: |
|                  0000                   |                  0                   |
|                  0001                   |                  0                   |
|                  0010                   |                  0                   |
|                  0011                   |                  0                   |
| <span style="color:#8FBF8F">0100</span> | <span style="color:#8FBF8F">1</span> |
| <span style="color:#8FBF8F">0101</span> | <span style="color:#8FBF8F">1</span> |
| <span style="color:#8FBF8F">0110</span> | <span style="color:#8FBF8F">1</span> |
| <span style="color:#8FBF8F">0111</span> | <span style="color:#8FBF8F">1</span> |
|                  1000                   |                  0                   |
| <span style="color:#8FBF8F">1001</span> | <span style="color:#8FBF8F">1</span> |
|                  1010                   |                  0                   |
| <span style="color:#8FBF8F">1011</span> | <span style="color:#8FBF8F">1</span> |
|                  1100                   |                  0                   |
| <span style="color:#8FBF8F">1101</span> | <span style="color:#8FBF8F">1</span> |
|                  1110                   |                  0                   |
|                  1111                   |                  0                   |

Следовательно, единичные наборы:

`0100, 0101, 0110, 0111, 1001, 1011, 1101`.

### <span style="color: #D58EAD;">Шаг 2. Записываем СДНФ</span>

<span style="color: #AE91CE;">Каждый</span> единичный набор <span style="color: #AE91CE;">превращаем</span> в минтерм. Если в наборе на месте переменной стоит 0, записываем её отрицание; если 1 - саму переменную.

$$\begin{aligned}
f={}&\neg x_1x_2\neg x_3\neg x_4\lor\neg x_1x_2\neg x_3x_4\\
&\lor\neg x_1x_2x_3\neg x_4\lor\neg x_1x_2x_3x_4\\
&\lor x_1\neg x_2\neg x_3x_4\lor x_1\neg x_2x_3x_4\\
&\lor x_1x_2\neg x_3x_4.
\end{aligned}$$

Например, набор `0101` даёт минтерм $\neg x_1x_2\neg x_3x_4$.

### <span style="color: #D58EAD;">Шаг 3. Первый раунд склеивания</span>

<span style="color: #AE91CE;">Два</span> минтерма <span style="color: #8FBF8F;">можно</span> <span style="color: #AE91CE;">склеить</span>, если они отличаются ровно <span style="color: #AE91CE;">одной</span> переменной. Отличающуюся переменную <span style="color: #AE91CE;">удаляем</span>.

Например:

$$\neg x_1x_2\neg x_3\neg x_4\lor\neg x_1x_2\neg x_3x_4=\neg x_1x_2\neg x_3.$$

В шаблоне `0` и `1` на месте различающейся переменной заменяются на `−`.

| Пара наборов | Отличается переменная | Результат |
| --- | --- | --- |
| `0100` и `0101` | $x_4$ | `010-` |
| `0100` и `0110` | $x_3$ | `01-0` |
| `0101` и `0111` | $x_3$ | `01-1` |
| `0101` и `1101` | $x_1$ | `-101` |
| `0110` и `0111` | $x_4$ | `011-` |
| `1001` и `1011` | $x_3$ | `10-1` |
| `1001` и `1101` | $x_2$ | `1-01` |

Другие пары единичных наборов отличаются более чем одной координатой и поэтому не склеиваются.

### <span style="color: #D58EAD;">Шаг 4. Второй раунд склеивания</span>

Теперь <span style="color: #AE91CE;">склеиваем</span> шаблоны с одинаковыми позициями прочерков:

| Пара шаблонов | Отличается переменная | Результат |
| --- | --- | --- |
| `010-` и `011-` | $x_3$ | `01--` |
| `01-0` и `01-1` | $x_4$ | `01--` |

Шаблоны `10-1`, `1-01` и `-101` дальше не склеиваются: для каждой пары различаются более одной фиксированной позиции либо позиции прочерков не совпадают.

<span style="color: #8FBF8F;">Получили</span> <span style="color: #AE91CE;">четыре</span> простые импликанты:

| Шаблон | Конъюнкт | Число букв |
| --- | --- | ---: |
| `01--` | $\neg x_1x_2$ | 2 |
| `10-1` | $x_1\neg x_2x_4$ | 3 |
| `1-01` | $x_1\neg x_3x_4$ | 3 |
| `-101` | $x_2\neg x_3x_4$ | 3 |

**Проверка перевода шаблона:** `1-01` означает $x_1=1$, $x_3=0$, $x_4=1$, поэтому конъюнкт равен $x_1\neg x_3x_4$.

<span style="color: #8FBF8F;">Склеивание закончилось</span>. Значит, полученные конъюнкты - все простые импликанты.

### <span style="color: #D58EAD;">Шаг 5. Записываем сокращённую ДНФ</span>

Сокращённая ДНФ содержит <span style="color: #AE91CE;">все</span> простые импликанты:

$$\boxed{\begin{aligned}
f={}&\neg x_1x_2\lor x_1\neg x_2x_4\\
&\lor x_1\neg x_3x_4\lor x_2\neg x_3x_4.
\end{aligned}}$$

Это сокращённая ДНФ. Чтобы найти тупиковые ДНФ, нужно выбрать из простых импликант такое покрытие, из которого нельзя удалить ни одного слагаемого.

---

## <span style="color: #D58EAD;">3. Таблица покрытия</span>

Обозначим простые импликанты:

- $A=\neg x_1x_2$;
- $B=x_1\neg x_2x_4$;
- $C=x_1\neg x_3x_4$;
- $D=x_2\neg x_3x_4$.

Теперь <span style="color: #AE91CE;">определим</span>, какие единичные наборы покрывает каждое слагаемое.

- $A$: $x_1=0$, $x_2=1$, а $x_3,x_4$ свободны. Наборы: `0100, 0101, 0110, 0111`.
- $B$: $x_1=1$, $x_2=0$, $x_4=1$, а $x_3$ свободна. Наборы: `1001, 1011`.
- $C$: $x_1=1$, $x_3=0$, $x_4=1$, а $x_2$ свободна. Наборы: `1001, 1101`.
- $D$: $x_2=1$, $x_3=0$, $x_4=1$, а $x_1$ свободна. Наборы: `0101, 1101`.

<span style="color: #AE91CE;">Составим</span> таблицу. Знак `×` ставим там, где слагаемое покрывает соответствующий единичный набор.

| Единичный набор | $A$ | $B$ | $C$ | $D$ |
| --- | :---: | :---: | :---: | :---: |
| `0100` | × |  |  |  |
| `0101` | × |  |  | × |
| `0110` | × |  |  |  |
| `0111` | × |  |  |  |
| `1001` |  | × | × |  |
| `1011` |  | × |  |  |
| `1101` |  |  | × | × |

### <span style="color: #D58EAD;">Как читать таблицу</span>

Например, в строке `0100` крестик стоит только под $A$. Значит, этот набор покрывается только $A$.

В строке `1001` крестики стоят под $B$ и $C$. Значит, этот набор можно покрыть одним из этих двух слагаемых.

### <span style="color: #D58EAD;">Находим обязательные импликанты</span>

<span style="color: #AE91CE;">Посмотрим</span> на строки, где есть только <span style="color: #AE91CE;">один</span> крестик:

- `0100` покрывается только $A$ - значит, $A$ обязательно входит в любую тупиковую ДНФ;
- `1011` покрывается только $B$ - значит, $B$ тоже обязательно входит.

После выбора $A$ и $B$ остаётся непокрытым набор `1101`. Его можно покрыть либо $C$, либо $D$.

<span style="color: #8FBF8F;">Получаем</span> <span style="color: #AE91CE;">два</span> варианта:

$$D_1=A\lor B\lor C,$$

$$D_2=A\lor B\lor D.$$

В развёрнутом виде:

$$\boxed{\begin{aligned}
D_1={}&\neg x_1x_2\lor x_1\neg x_2x_4\lor x_1\neg x_3x_4;\\
D_2={}&\neg x_1x_2\lor x_1\neg x_2x_4\lor x_2\neg x_3x_4.
\end{aligned}}$$

---

## <span style="color: #D58EAD;">4. Проверяем, что обе ДНФ тупиковые</span>

Для тупиковой ДНФ нужно доказать <span style="color: #AE91CE;">две</span> вещи:

1. Все единичные наборы функции покрыты.
2. Ни одно слагаемое нельзя удалить.

### <span style="color: #D58EAD;">Проверка</span> $D_1=A\lor B\lor C$

Покрытие:

- $A$ покрывает `0100, 0101, 0110, 0111`;
- $B$ покрывает `1001, 1011`;
- $C$ покрывает `1001, 1101`.

Все единичные наборы исходного вектора перечислены: `0100, 0101, 0110, 0111, 1001, 1011, 1101`. Значит, они все покрыты.

Теперь <span style="color: #AE91CE;">удаляем</span> слагаемые по одному:

- без $A$ потеряется набор `0100`;
- без $B$ потеряется набор `1011`;
- без $C$ потеряется набор `1101`.

Ни одно слагаемое удалить нельзя. Следовательно, $D_1$ - тупиковая ДНФ.

### <span style="color: #D58EAD;">Проверка</span> $D_2=A\lor B\lor D$

Покрытие:

- $A$ покрывает `0100, 0101, 0110, 0111`;
- $B$ покрывает `1001, 1011`;
- $D$ покрывает `0101, 1101`.

Все единичные наборы также покрыты.

Теперь удаляем слагаемые по одному:

- без $A$ потеряется набор `0100`;
- без $B$ потеряется набор `1011`;
- без $D$ потеряется набор `1101`.

Ни одно слагаемое удалить нельзя. Следовательно, $D_2$ - тоже тупиковая ДНФ.

### <span style="color: #D58EAD;">Почему других тупиковых ДНФ нет</span>

$A$ и $B$ обязательны: у каждого есть единичный набор, который покрывает только эта импликанта. После выбора $A$ и $B$ остаётся покрыть `1101`. Его покрывают только $C$ и $D$.

Поэтому возможны только $A\lor B\lor C$ и $A\lor B\lor D$. Других вариантов таблица покрытия не даёт.

---

## <span style="color: #D58EAD;">5. Находим минимальные ДНФ</span>

<span style="color: #AE91CE;">Считаем</span> количество букв (литералов) в каждом слагаемом:

| ДНФ | Подсчёт | Всего букв | Количество слагаемых |
| --- | --- | ---: | ---: |
| $D_1=A\lor B\lor C$ | $2+3+3$ | 8 | 3 |
| $D_2=A\lor B\lor D$ | $2+3+3$ | 8 | 3 |

Обе ДНФ имеют одинаковое количество букв и одинаковое количество слагаемых.

$$\boxed{\text{Минимальные ДНФ: }D_1\text{ и }D_2}$$

---

## <span style="color: #D58EAD;">6. Частые ошибки</span>

- Сокращённая ДНФ содержит все простые импликанты, а тупиковая - только выбранное покрытие.
- <span style="color: #e0313a;">Нельзя</span> объявить ДНФ тупиковой, не проверив удаление каждого слагаемого.
- <span style="color: #e0313a;">Нельзя</span> утверждать, что найдены все тупиковые ДНФ, если проверено только одно покрытие.
- Все единичные наборы должны быть покрыты. Нулевые наборы не должны покрываться ни одной выбранной импликантой.
- Если минимизируем по числу букв, считаем все литералы, в том числе отрицания.
