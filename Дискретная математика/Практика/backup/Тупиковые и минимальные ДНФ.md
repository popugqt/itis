### <span style="background-color:rgba(213, 142, 173, 0.30)">Тупиковые и минимальные ДНФ</span>

---

##### <span style="color:#D58EAD">Тупиковая ДНФ</span> - <span style="color:#D58EAD">ДНФ</span>, в которой:
- все слагаемые являются <span style="color:#D58EAD">простыми импликантами</span>
- <span style="color:#e0313a">нельзя</span> <span style="color:#AE91CE">удалить</span> <span style="color:#AE91CE">ни одно</span> слагаемое, <span style="color:#AE91CE">не изменив</span> функцию


У одной функции может быть <span style="color:#AE91CE">несколько</span> <span style="color:#D58EAD">тупиковых ДНФ</span>

<span style="color:#D58EAD">Минимальная ДНФ</span> - одна из <span style="color:#D58EAD">тупиковых</span> с <span style="color:#AE91CE">наименьшим количеством букв</span> по выбранному критерию
