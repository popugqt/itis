### <span style="background-color:rgba(213, 142, 173, 0.30)">Полнота системы и базисы</span>
---
##### Допустим, у нас есть <span style="color:#D58EAD">система</span>:
$$F=\{f_1,f_2,f_3,f_4\}$$
##### Составляем <span style="color:#D58EAD">таблицу</span>

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| ------- | ----- | ----- | --- | --- | --- |
| $f_1$   | +     | +     | −   | +   | −   |
| $f_2$   | +     | −     | +   | −   | +   |
| $f_3$   | −     | +     | +   | +   | +   |
| $f_4$   | +     | +     | +   | −   | +   |
`+` ставится, если функция <span style="color:#8FBF8F">принадлежит</span> <span style="color:#D58EAD">классу</span>, `-` ставится, если функция <span style="color:#E06C75">не принадлежит</span> <span style="color:#D58EAD">классу</span>

---
#### Шаг 1. Проверяем <span style="color:#D58EAD">полноту системы</span>

> **<span style="background-color:rgba(214, 184, 90, 0.32)">Теорема Поста</span>**
> Система <span style="color:#D58EAD">полна</span> тогда и только тогда, когда <span style="color:#AE91CE">в каждом</span> из пяти <span style="color:#AE91CE">столбцов</span> есть <span style="color:#AE91CE">хотя бы один минус</span>

В нашем примере <span style="color:#AE91CE">в каждом столбце</span> есть `-`, следовательно, система <span style="color:#D58EAD">полная</span>

---
#### Шаг 2. Находим <span style="color:#D58EAD">базисы</span>

> **<span style="color:#D58EAD">Базис</span>** - это минимальная полная подсистема

##### Алгоритм:
1. Берем <span style="color:#D58EAD">исходную систему</span>
2. Удаляем <span style="color:#AE91CE">одну</span> функцию
3. Проверяем, остался ли хотя бы <span style="color:#AE91CE">один минус в каждом столбце</span>
4. Если остался - функция <span style="color:#AE91CE">не нужна</span>
5. Повторяем для остальных функций

В результате получаем <span style="color:#D58EAD">базис</span>

> **<span style="background-color:rgba(224, 108, 117, 0.28)">Важно!</span>**
> Если нужно найти все <span style="color:#D58EAD">базисы</span>, необходимо проверить все возможные <span style="color:#D58EAD">подмножества</span>. Простое последовательное удаление может найти **<span style="color:#e0313a">только один</span>** из них

---

### Пример
#### 1. Исходная <span style="color:#D58EAD">система</span>

Допустим, у нас есть четыре функции:

$$
F=\{f_1,f_2,f_3,f_4\}
$$

После проверки <span style="color:#D58EAD">классов Поста</span> получили <span style="color:#D58EAD">таблицу</span>:

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| ------- | ----- | ----- | --- | --- | --- |
| $f_1$   | −     | +     | −   | +   | +   |
| $f_2$   | +     | −     | −   | +   | −   |
| $f_3$   | +     | +     | −   | −   | +   |
| $f_4$   | +     | +     | −   | −   | +   |
|         |       |       |     |     |     |
<span style="color:#D58EAD">В каждом столбце</span> <span style="color:#8FBF8F">есть минусы</span>, значит <span style="color:#D58EAD">система полная</span>

#### 2. Поиск <span style="color:#D58EAD">базисов</span>

Попробуем убрать $f_4$.

Получаем:

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| --- | --- | --- | --- | --- | --- |
| $f_1$ | − | + | − | + | + |
| $f_2$ | + | − | − | + | − |
| $f_3$ | + | + | − | − | + |

<span style="color:#AE91CE">Все столбцы</span> по-прежнему <span style="color:#8FBF8F">имеют минусы</span>, значит $f_4$ - <span style="color:#D58EAD">базис</span>

Теперь попробуем убрать любую оставшуюся функцию:
- Убираем $f_1$ - в $T_0$ больше <span style="color:#E06C75">нет минусов</span>
- Убираем $f_2$ - в $T_1$ и $M$ больше <span style="color:#E06C75">нет минусов</span>
- Убираем $f_3$ - в $L$ больше <span style="color:#E06C75">нет минусов</span>

Удалить больше ничего <span style="color:#E06C75">нельзя</span>

$$\boxed{B_1=\{f_1,f_2,f_3\}}$$
#### 3. Второй <span style="color:#D58EAD">базис</span>

Вернёмся к исходной <span style="color:#D58EAD">таблице</span> и попробуем убрать не $f_4$, а $f_3$

Получаем:

| Функция | $T_0$ | $T_1$ | $S$ | $L$ | $M$ |
| --- | --- | --- | --- | --- | --- |
| $f_1$ | − | + | − | + | + |
| $f_2$ | + | − | − | + | − |
| $f_4$ | + | + | − | − | + |

Снова <span style="color:#AE91CE">все столбцы</span> <span style="color:#8FBF8F">имеют минусы</span>

И снова убрать ни одну функцию <span style="color:#E06C75">нельзя</span>

$$\boxed{B_2=\{f_1,f_2,f_4\}}$$
#### 4. Почему получилось два <span style="color:#D58EAD">базиса</span>?

Посмотрим на исходную <span style="color:#D58EAD">таблицу</span>:
1. $f_1$ - <span style="color:#E06C75">единственная функция с минусом</span> в $T_0$
2. $f_2$ - <span style="color:#E06C75">единственная функция с минусом</span> в $T_1$ и $M$
3. $f_3$ и $f_4$ - обе <span style="color:#8FBF8F">имеют минус</span> в $L$

Поэтому <span style="color:#E06C75">обязательно нужны</span> $f_1, f_2$ и <span style="color:#8FBF8F">хотя бы одна</span> из функций $f_3, f_4$

#### Получается два варианта:
$$
\boxed{
B_1=\{f_1,f_2,f_3\}\\
B_2=\{f_1,f_2,f_4\}
}
$$
#### 5. Алгоритм решения
1. Проверяем, что исходная <span style="color:#D58EAD">система полная</span>
2. Ищем столбцы, в которых есть только <span style="color:#8FBF8F">один минус</span>. Соответствующие функции обязательно входят в каждый <span style="color:#D58EAD">базис</span>
3. Проверяем остальные комбинации функций, чтобы <span style="color:#AE91CE">в каждом столбце</span> оставался <span style="color:#AE91CE">хотя бы один минус</span>
4. Проверяем, можно ли удалить еще какую-нибудь функцию
5. Записываем полученные <span style="color:#D58EAD">базисы</span>
