# <span style="background-color: rgba(213, 142, 173, 0.30);">Полином Жегалкина</span>

---

## <span style="background-color: rgba(213, 142, 173, 0.30);">1. Операции и основные тождества</span>

**<span style="color: #D58EAD;">Полином Жегалкина</span>** строится из трёх элементов:

- <span style="color: #D58EAD;">XOR</span> — сложение по модулю 2, обозначается $\oplus$;
- <span style="color: #D58EAD;">AND</span> — умножение, обозначается точкой или простым соседством переменных;
- свободный член — константа 0 или 1.

Основные равенства:

$$0\oplus a=a,\qquad 1\oplus1=0,\qquad a\oplus a=0.$$

$$a\cdot0=0,\qquad a\cdot1=a,\qquad a\cdot a=a.$$

Последнее равенство означает, что в булевом полиноме $x_i^2=x_i$.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Как заменить обычные операции</span>

$$\neg x=1\oplus x$$
$$x\land y=xy$$
$$x\lor y=x\oplus y\oplus xy$$
$$x\to y=1\oplus x\oplus xy$$
$$x\leftrightarrow y=1\oplus x\oplus y$$

Проверим формулу для импликации:

| $x$ | $y$ | $x\to y$ | $1\oplus x\oplus xy$ |
| ---: | ---: | ---: | ---: |
| 0 | 0 | 1 | 1 |
| 0 | 1 | 1 | 1 |
| 1 | 0 | 0 | 0 |
| 1 | 1 | 1 | 1 |

Столбцы совпадают, значит, тождество верно.

## <span style="background-color: rgba(213, 142, 173, 0.30);">2. Общий вид полинома</span>

Для двух переменных:

$$f(x_1,x_2)=a_0\oplus a_1x_1\oplus a_2x_2\oplus a_{12}x_1x_2.$$

Для четырёх переменных:

$$\begin{aligned}
f={}&a_0\oplus a_1x_1\oplus a_2x_2\oplus a_3x_3\oplus a_4x_4\\
&\oplus a_{12}x_1x_2\oplus a_{13}x_1x_3\oplus a_{14}x_1x_4\\
&\oplus a_{23}x_2x_3\oplus a_{24}x_2x_4\oplus a_{34}x_3x_4\\
&\oplus a_{123}x_1x_2x_3\oplus a_{124}x_1x_2x_4\\
&\oplus a_{134}x_1x_3x_4\oplus a_{234}x_2x_3x_4\\
&\oplus a_{1234}x_1x_2x_3x_4.
\end{aligned}$$

Каждый коэффициент $a$ равен 0 или 1. Коэффициенты, равные 0, в итоговом полиноме не записываются.

## <span style="background-color: rgba(213, 142, 173, 0.30);">3. Способ №1. Алгебраические преобразования</span>

Этот способ удобен, когда функция задана формулой.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Алгоритм</span>

1. <span style="color: #AE91CE;">Замени</span> каждую обычную операцию на выражение через $\oplus$ и умножение.
2. <span style="color: #AE91CE;">Раскрой</span> скобки по распределительному закону.
3. <span style="color: #AE91CE;">Удали</span> одинаковые слагаемые попарно, потому что $A\oplus A=0$.
4. <span style="color: #AE91CE;">Упрости</span> степени по правилу $x_i^2=x_i$.
5. <span style="color: #AE91CE;">Запиши</span> оставшиеся слагаемые в виде полинома Жегалкина.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Пример из образца:</span> $f_1$

Если первая формула действительно имеет вид

$$f_1=(1\lor x_2x_3)\to x_2x_3,$$

то сначала:

$$1\lor x_2x_3=1.$$

<span style="color: #8FBF8F;">Следовательно</span>:

$$f_1=1\to x_2x_3=x_2x_3.$$

Итог:

$$\boxed{f_1=x_2x_3}$$

Это уже полином Жегалкина: здесь есть только произведение переменных.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Пример из образца:</span> $f_3$

Пусть

$$f_3=(x_2\to x_3x_4)\to x_1x_3.$$

<span style="color: #AE91CE;">Сначала</span> <span style="color: #AE91CE;">преобразуем</span> внутреннюю импликацию:

$$x_2\to x_3x_4=1\oplus x_2\oplus x_2x_3x_4.$$

<span style="color: #AE91CE;">Обозначим</span> полученное выражение через $A$:

$$A=1\oplus x_2\oplus x_2x_3x_4.$$

Тогда внешняя импликация:

$$f_3=A\to x_1x_3=1\oplus A\oplus Ax_1x_3.$$

<span style="color: #AE91CE;">Подставляем</span> $A$:

$$\begin{aligned}
f_3={}&1\oplus(1\oplus x_2\oplus x_2x_3x_4)\\
&\oplus(1\oplus x_2\oplus x_2x_3x_4)x_1x_3.
\end{aligned}$$

<span style="color: #AE91CE;">Раскрываем</span> скобки:

$$\begin{aligned}
f_3={}&1\oplus1\oplus x_2\oplus x_2x_3x_4\\
&\oplus x_1x_3\oplus x_1x_2x_3\oplus x_1x_2x_3^2x_4.
\end{aligned}$$

<span style="color: #AE91CE;">Учитываем</span> $1\oplus1=0$ и $x_3^2=x_3$:

$$\boxed{f_3=x_2\oplus x_2x_3x_4\oplus x_1x_3\oplus x_1x_2x_3\oplus x_1x_2x_3x_4}$$

## <span style="background-color: rgba(213, 142, 173, 0.30);">4. Способ №2. Преобразование вектора значений</span>

Этот способ удобен, когда функция задана вектором значений. Его также называют преобразованием Мёбиуса или методом треугольника.

Для вектора из $2^n$ значений последовательно выполняем сложение по модулю 2. В результате получаем коэффициенты полинома Жегалкина.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Пример из образца:</span> $f_2$

Дан вектор:

$$f_2=(1001100101100110).$$

Порядок наборов: от `0000` до `1111`. <span style="color: #AE91CE;">Начинаем</span> с исходного вектора и <span style="color: #AE91CE;">обрабатываем</span> переменные $x_4$, $x_3$, $x_2$, $x_1$ именно в таком порядке.

На шаге с расстоянием $d$ для каждого индекса $i$, у которого соответствующий двоичный разряд равен 1, выполняем:

$$a_i\leftarrow a_i\oplus a_{i-d}.$$

Расстояния идут так: $d=1,2,4,8$.

| Этап | Полученный вектор |
| --- | --- |
| Исходный | `1001100101100110` |
| После обработки $x_4$ ($d=1$) | `1101110101110111` |
| После обработки $x_3$ ($d=2$) | `1110111001100110` |
| После обработки $x_2$ ($d=4$) | `1110000001100000` |
| После обработки $x_1$ ($d=8$) | `1110000010000000` |

В последнем векторе единицы стоят на позициях:

- `0000` — свободный коэффициент $a_0=1$;
- `0001` — коэффициент при $x_4$: $a_4=1$;
- `0010` — коэффициент при $x_3$: $a_3=1$;
- `1000` — коэффициент при $x_1$: $a_1=1$.

Остальные коэффициенты равны 0. Поэтому:

$$\boxed{f_2=1\oplus x_1\oplus x_3\oplus x_4}$$

> **<span style="background-color: rgba(224, 108, 117, 0.28);">Важно!</span>**
> Порядок переменных при преобразовании должен совпадать с порядком наборов в исходном векторе. Если $x_1$ меняется быстрее, чем $x_4$, последовательность шагов будет другой.

## <span style="background-color: rgba(213, 142, 173, 0.30);">5. Способ №3. Система уравнений для коэффициентов</span>

Этот способ похож на тот, который уже есть в конспекте для двух переменных. Он подходит и для трёх, четырёх и большего числа переменных.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Алгоритм</span>

1. <span style="color: #AE91CE;">Запиши</span> общий полином со всеми возможными коэффициентами.
2. <span style="color: #AE91CE;">Подставляй</span> наборы из таблицы истинности в порядке от `00...0` до `11...1`.
3. <span style="color: #AE91CE;">Получай</span> уравнения относительно коэффициентов.
4. <span style="color: #AE91CE;">Решай</span> систему по модулю 2.
5. Коэффициенты, равные 1, <span style="color: #AE91CE;">оставляй</span> в полиноме; коэффициенты, равные 0, удаляй.

### <span style="background-color: rgba(213, 142, 173, 0.30);">Пример: найдём полином для</span> $f_3$

Исходная функция:

$$f_3=(x_2\to x_3x_4)\to x_1x_3.$$

Её вектор значений в принятом порядке:

$$f_3=(0000111000111111).$$

Для <span style="color: #AE91CE;">четырёх</span> переменных общий полином содержит <span style="color: #AE91CE;">16</span> коэффициентов. Чтобы не переписывать каждый раз весь полином, будем подставлять наборы по порядку. На каждом следующем шаге уже найденные коэффициенты известны.

| Набор | $f_3$ | Уравнение после подстановки предыдущих коэффициентов | Новый коэффициент |
| --- | ---: | --- | --- |
| `0000` | 0 | $a_0=0$ | $a_0=0$ |
| `0001` | 0 | $a_0\oplus a_4=0$ | $a_4=0$ |
| `0010` | 0 | $a_0\oplus a_3=0$ | $a_3=0$ |
| `0011` | 0 | $a_0\oplus a_3\oplus a_4\oplus a_{34}=0$ | $a_{34}=0$ |
| `0100` | 1 | $a_0\oplus a_2=1$ | $a_2=1$ |
| `0101` | 1 | $a_0\oplus a_2\oplus a_4\oplus a_{24}=1$ | $a_{24}=0$ |
| `0110` | 1 | $a_0\oplus a_2\oplus a_3\oplus a_{23}=1$ | $a_{23}=0$ |
| `0111` | 0 | $a_0\oplus a_2\oplus a_3\oplus a_4\oplus a_{23}\oplus a_{24}\oplus a_{34}\oplus a_{234}=0$ | $a_{234}=1$ |
| `1000` | 0 | $a_0\oplus a_1=0$ | $a_1=0$ |
| `1001` | 0 | $a_0\oplus a_1\oplus a_4\oplus a_{14}=0$ | $a_{14}=0$ |
| `1010` | 1 | $a_0\oplus a_1\oplus a_3\oplus a_{13}=1$ | $a_{13}=1$ |
| `1011` | 1 | $a_0\oplus a_1\oplus a_3\oplus a_4\oplus a_{13}\oplus a_{14}\oplus a_{34}\oplus a_{134}=1$ | $a_{134}=0$ |
| `1100` | 1 | $a_0\oplus a_1\oplus a_2\oplus a_{12}=1$ | $a_{12}=0$ |
| `1101` | 1 | $a_0\oplus a_1\oplus a_2\oplus a_4\oplus a_{12}\oplus a_{14}\oplus a_{24}\oplus a_{124}=1$ | $a_{124}=0$ |
| `1110` | 1 | $a_0\oplus a_1\oplus a_2\oplus a_3\oplus a_{12}\oplus a_{13}\oplus a_{23}\oplus a_{123}=1$ | $a_{123}=1$ |
| `1111` | 1 | сумма всех коэффициентов равна 1 | $a_{1234}=1$ |

Для последней строки уже известные ненулевые коэффициенты — $a_2$, $a_{13}$, $a_{123}$ и $a_{234}$. Их сумма по модулю 2 равна 0, поэтому из уравнения для набора `1111` получаем $a_{1234}=1$.

Итоговые коэффициенты:

$$\begin{aligned}
&a_0=0,\quad a_1=0,\quad a_2=1,\quad a_3=0,\quad a_4=0,\\
&a_{12}=0,\quad a_{13}=1,\quad a_{14}=0,\quad a_{23}=0,\quad a_{24}=0,\quad a_{34}=0,\\
&a_{123}=1,\quad a_{124}=0,\quad a_{134}=0,\quad a_{234}=1,\quad a_{1234}=1.
\end{aligned}$$

Следовательно:

$$\boxed{f_3=x_2\oplus x_1x_3\oplus x_1x_2x_3\oplus x_2x_3x_4\oplus x_1x_2x_3x_4}$$

Это тот же результат, что и при алгебраических преобразованиях. Порядок слагаемых может отличаться — на значение полинома это не влияет.

## <span style="background-color: rgba(213, 142, 173, 0.30);">6. Как проверить линейность по полиному</span>

Функция принадлежит классу $L$, если степень её полинома Жегалкина не выше 1:

$$f=a_0\oplus a_1x_1\oplus\cdots\oplus a_nx_n.$$

Свободный член допускается. Поэтому, например:

$$1\oplus x_1\oplus x_2\in L.$$

Если есть хотя бы одно произведение двух или более различных переменных, например $x_1x_2$ или $x_1x_2x_3$, функция <span style="color: #e0313a;">не принадлежит</span> $L$.

## <span style="background-color: rgba(213, 142, 173, 0.30);">7. Какой метод выбрать на контрольной</span>

| Как задана функция | Удобный метод |
| --- | --- |
| Формулой с $\neg,\land,\lor,\to$ | Алгебраические преобразования |
| Вектором значений | Преобразование Мёбиуса / треугольник |
| Нужно получить коэффициенты через уравнения | Система уравнений для коэффициентов |

В образце можно распределить <span style="color: #AE91CE;">три</span> разных метода между функциями:

- $f_1$ — алгебраические преобразования;
- $f_2$ — преобразование вектора;
- $f_3$ — система уравнений для коэффициентов.

Для $f_4$ сначала нужно точно прочитать исходные знаки операций. По искажённой записи строить полином <span style="color: #e0313a;">нельзя</span>.
