# <span style="background-color: rgba(213, 142, 173, 0.30);">Элементарные преобразования</span>

#ЭлементарныеПреобразования

| Преобразование | Влияние на $\det{A}$ |
| ---- | ---- |
| Перестановка двух строк | Определитель <span style="color: #e0313a;">меняет знак</span> |
| Умножение строки на число $k$ | Определитель умножается на число $k$ |
| Прибавление к строке другой строки, умноженной на число $k$ | Определитель <span style="color: #8FBF8F;">не меняется</span> |
