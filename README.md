## Что внутри

Заметки/конспекты в Markdown с формулами LaTeX

---

## Как открыть

1. Установите Obsidian
2. Склонируйте репозиторий: git clone URL-репозитория
3. В Obsidian выберите **Open folder as vault** и укажите папку

Формулы работают через стандартный MathJax: строчные - `$...$`, блочные - `$$...$$`
